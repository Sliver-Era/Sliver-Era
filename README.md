# 白银纪元 · 工作站文档（Doc 分支）

本仓库是「白银纪元」的**工作站文档仓库**，位于项目工作区之外，通过远端 `Doc` 分支发布。这里只保存开发过程文档与维护脚本，**不含项目源码、构建产物或第三方库**。

项目源码分布在若干独立层仓库中，各自推送远端的不同分支；本分支只承载与代码版次配套的文档索引。

---

## 一、仓库与分支信息

| 项目 | 取值 |
| --- | --- |
| 仓库地址（现行） | `https://github.com/Sliver-Era/Sliver-Era.git` |
| 旧地址 | `https://github.com/yuxingyuzhong/SilverEra.git`（GitHub 重定向到现行地址） |
| 远端名 | `origin` |
| 本地分支名 | `Doc` |
| 远端目标分支 | `Doc` |
| 上游跟踪 | `origin/Doc` |
| 推送命令 | `git push origin Doc:Doc` |

同一远端承载的代码分支：`EngineFoundation`、`EngineSystem`、`Test`、`Game`、`main`（顶层总览与聚合快照），以及 `Engine`（聚合快照）与 `EngineRender`（渲染层快照）。渲染层活跃源码位于独立仓库 `SilverEra-Renderer`。

### 3.1 存储约定

- **任务报告**：目录名 = 新增功能/修复点 ＋ 代码推送哈希值，两者用 `_` 连接；报告内记录相对项目根的路径。
- **项目导航**：版次目录以代码推送哈希值命名；分支目录下维护 `分支提交历史`，记录提交顺序与每版次新增功能。
- **自主迭代**：计划与报告按固定分册格式书写（每分册最多 25 轮），正文逐字保留；索引每份上限 500 轮。渲染核心见 `自主迭代合集/渲染核心/索引/`，本作见 `自主迭代合集/游戏层/索引/`。

## 四、维护脚本

| 脚本 | 用途 |
| --- | --- |
| `升级测试锁.ps1` | 把当前各层构建树版本成套写入 `Engine/版本锁.cmake`（三层 × Debug/Release 六条） |
| `导航体检.ps1` | 对照源码改动检查项目导航文档是否过期 |
| `构建双配置.ps1` | 按 Debug / Release 两棵构建树构建各层 |
| `检查/下层与测试层同步检查.ps1` | 检查下层静态库与测试层链接口径是否一致 |
| `检查/后处理alpha守卫.ps1` | 校验后处理着色器的 alpha 透传约定 |
| `检查/测试辅助重复检查.ps1` | 检测测试用例重复实现公共辅助逻辑 |
| `检查/源码行数统计.ps1` | 统计各层源码行数 |

## 五、不入库内容

以下内容体积大或可按需重新生成，已列入 `.gitignore`：

- `临时/`：本地临时工作区与源码/构建快照；
- `下层库快照/`：已构建静态库与头快照；
- `*.lib`、`*.exe`、`*.obj`、`*.pdb` 等构建产物；
- `.vs/`、检查脚本生成的日志。
