## 二、关键约定

- 方块编号：空气 0 / 草 1 / 土 2 / 石 3 / 沙 4 / 水 5；进入存档后只允许追加，不得改号。
- 区块尺寸：单轴 16，体积 4096；存储为 `std::array<方块类型, 4096>`，无动态分配。
- 线性索引：`index = x + z * 16 + y * 256`；`索引获取` 越界返回 -1，`坐标获取` 越界返回假。
- 越界读取返回空气，越界写入返回假且不改动数据。

## 四、自检覆盖项

1. 默认区块全空气、非空气计数为 0、区块坐标为零。
2. 区块坐标构造与 `坐标设置`。
3. 单点写入/读取一致，计数为 1。
4. 负坐标与 X/Y/Z 越界读取返回空气。
5. 负坐标与越界写入被拒绝，数据不变。
6. 填充后非空气数量为 4096，边界点可读；再填充空气后全空。
7. 全部 4096 个坐标的索引唯一、与约定公式一致、反解坐标往返一致。
8. 越界索引返回 -1，越界索引反解被拒绝。
9. `sizeof(区块数据)` 不超过体积 + 64 字节，确认无额外动态结构。

## 五、复开发路径

1. 世界侧数据放 `src/世界/`，纯数据实现放 `core/`，对外头文件放模块根。
2. 任何涉及方块存储的新接口必须复用 `索引获取` / `坐标获取`，不得另立索引顺序。
3. 新增方块类型只能追加到 `方块类型` 末尾，并同步 `方块类型数量`。
4. 新增世界自检沿用 `--xxx-test` 纯数据入口，不初始化渲染器。
