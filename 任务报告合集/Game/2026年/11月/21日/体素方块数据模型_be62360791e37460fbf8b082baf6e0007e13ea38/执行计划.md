# 执行计划 · 体素方块数据模型（第 9 轮）

> 代码推送哈希：`be62360791e37460fbf8b082baf6e0007e13ea38` ｜ 类型：方向深研轮（游戏框架搭建 / 阶段 C）

## 一、目标

在框架层之外建立世界侧最小体素数据结构，作为后续区块管理器、区块网格生成与存档的稳定底座。
本轮只做纯数据与边界校验，不接渲染、不做文件 IO。

## 二、分段执行

### 阶段 1：方块类型

- 新增 `src/世界/体素类型.h`：`方块类型` 枚举（空气 0 / 草 1 / 土 2 / 石 3 / 沙 4 / 水 5），底层 `std::uint8_t`。
- 新增 `src/世界/core/体素类型.cpp`：名称查询；越界值返回「未知」。

### 阶段 2：区块数据

- 新增 `src/世界/区块数据.h`：
  - `区块边长 = 16`、`区块体积 = 4096`；
  - 区块坐标与 `std::array<方块类型, 4096>`；
  - 读写、填充、全空判断、非空气计数、索引互转、只读数组访问。
- 新增 `src/世界/core/区块数据.cpp`：全部接口实现。
- 索引约定：`index = x + z * 16 + y * 256`；越界索引返回 -1，越界读写不触碰存储。

### 阶段 3：自检入口

- 新增 `src/世界/core/体素自检.cpp`：默认全空、坐标构造/设置、单点读写、越界读写、填充计数、索引唯一与往返、内存占用上限。
- `src/框架/应用配置.h/.cpp`：新增 `体素自检` 与 `--voxel-test`。
- `src/主调/主程序.cpp`：日志初始化后直接执行并返回，不初始化渲染器。

## 四、验收口径

- Debug / Release 双配置构建零错误。
- `--voxel-test` 返回 0；既有七条自检（self / state / module / config / path / resource / log）均返回 0。
- 区块内存固定、无动态分配；越界访问不崩溃。
- 方块编号与索引布局写入项目导航，作为存档稳定约定。

## 五、风险与回退

- 索引顺序进入存档后难改：首版固定并用自检锁定。
- 16³ 区块容量偏小但可控；扩到 32³ 必须同时提供存档版本迁移，本轮不做。
- 纯数据层不得包含渲染或文件 IO；网格生成顺延至第 11 轮。
