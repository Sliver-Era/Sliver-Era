# 执行计划 · 区块管理器与加载卸载边界（第 10 轮）

> 代码推送哈希：`c68acc4396faca3ff162d9735fcc1f8bacf05292` ｜ 类型：方向深研轮（游戏框架搭建 / 阶段 C）

## 一、目标

把单区块数据扩展为多区块世界：建立区块坐标到区块数据的映射、半径内按需创建与范围外卸载，
为第 11 轮区块网格生成提供可遍历的区块集合。本轮仍不接渲染。

## 二、分段执行

### 阶段 1：区块坐标

- 新增 `src/世界/区块坐标.h`：`区块坐标 { x, y, z }`、相等/不等比较、`区块坐标哈希`。
- 新增 `src/世界/core/区块坐标.cpp`：FNV-1a 三轴混合哈希。

### 阶段 2：区块管理器

- 新增 `src/世界/区块管理器.h`：
  - `区块容量默认 = 512`；
  - `区块获取`（可变/常量）、`区块确保`、`区块卸载`、`区块数量`、`容量获取`、`清空`；
  - `半径更新(中心坐标, 半径)`，只保留中心 Y 层方形范围；
  - 只读 `区块表获取()`。
- 新增 `src/世界/core/区块管理器.cpp`：
  - `unordered_map<区块坐标, unique_ptr<区块数据>>` 存储；
  - 容量满拒绝并警告；分配用 `new (std::nothrow)`；
  - 半径更新先卸载范围外，再补齐范围内。

### 阶段 3：接入与自检

- 新增 `src/世界/core/区块管理器自检.cpp`：空表、确保/获取、卸载、半径收缩、换层、容量上限、卸载重建、坐标比较与哈希。
- `src/框架/应用配置.h/.cpp`：新增 `区块自检` 与 `--chunk-test`。
- `src/框架/游戏应用.h/.cpp`：持有 `区块管理器 世界区块`；初始化加载原点半径 1（9 个），关闭清空。
- `src/主调/主程序.cpp`：区块自检日志初始化后直接返回。

## 四、验收口径

- Debug / Release 双配置构建零错误。
- `--chunk-test` 与既有八条自检（voxel / self / state / module / config / path / resource / log）均返回 0。
- 区块管理器不依赖渲染器与文件 IO；卸载后不残留悬空指针。
- 加载半径语义（水平方形、单层）写入文档。

## 五、风险与回退

- `unordered_map` 迭代顺序不稳定：对外只提供只读表，不假设顺序。
- 每区块约 4 KB：容量必须显式限制，半径配置不得绕过容量检查。
- 本轮不做网格与邻接回调，留到第 11 轮。
