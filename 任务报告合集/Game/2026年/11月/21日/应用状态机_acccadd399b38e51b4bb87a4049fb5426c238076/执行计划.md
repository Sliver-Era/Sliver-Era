# 执行计划 · 应用状态机与统一退出路径（第 3 轮）

> 工作区：`Application/Game/Sliver-Era` ｜ 分支：main ｜ 计划时间：2026-11-21

## 一、开发任务

为游戏应用建立启动 / 游戏中 / 暂停 / 退出四态与统一状态切换入口，把窗口关闭、自检退出、暂停恢复收敛到同一套路径。

## 二、预修改文件

- `src/框架/应用配置.h`
- `src/框架/core/应用配置.cpp`
- `src/框架/游戏应用.h`
- `src/框架/core/游戏应用.cpp`

## 三、实现方式

1. `应用状态` 枚举与 `state_set` / `state_get`。
2. 合法迁移表：启动 → 游戏中 / 退出；游戏中 ↔ 暂停；任意 → 退出；非法迁移拒绝并记录。
3. 主循环按状态分派：仅游戏中推进固定更新；暂停清零累加器，只渲染。
4. 窗口关闭、更新达标、最大帧数统一走退出状态。
5. `--state-test` 时间脚本：0.10 s 暂停、0.30 s 校验暂停期更新不增长并恢复、0.60 s 校验恢复后增长并退出。

## 四、分段执行

1. 状态枚举与迁移表。
2. 主循环分派改造。
3. 自检脚本与配置项。
4. Debug / Release 构建。
5. 三条自检命令验证。
6. 提交与文档同步。

## 五、验收口径

- 双配置构建零错误。
- `--state-test`、`--self-test`、`--updates 120 --hidden` 均返回 0。
- 暂停期间固定更新次数不增长，恢复后继续增长。
- 不修改 `external/Engine` 版本锁，不新增外部库。
