# 执行计划 · 方块射线拾取与破坏放置（第 16 轮）

> 代码推送哈希：`fdb2f6bd668b3dcbf7db1909ca0c9426e759a331` ｜ 类型：方向深研轮（游戏框架搭建 / 阶段 D）

## 一、目标

让世界可交互：DDA 体素射线拾取命中方块，左键破坏、右键放置，并在修改后重建受影响区块网格。

## 二、分段执行

### 阶段 1：射线检测

- 新增 `src/世界/方块射线.h` / `core/方块射线.cpp`：
  - `射线命中`：是否命中、坐标、进入面法向、距离；
  - 方向内部归一；零向量/零距离返回未命中；
  - 起点方块优先检测；逐轴选择最小 tMax 步进；跳过非固体。

### 阶段 2：方块交互

- 新增 `src/世界/方块交互.h` / `core/方块交互.cpp`：
  - 世界坐标 ↔ 区块/局部坐标（向下取整）；
  - `方块破坏`：固体改空气；
  - `方块放置`：仅空气/水写入；
  - `命中破坏` / `命中放置`（放置坐标 = 命中 + 法向）；
  - `交互自检运行`：命中、法向、距离、未命中、负坐标、破坏与放置。

### 阶段 3：接入与自检

- `src/框架/应用配置.h/.cpp`：`交互自检` 与 `--interact-test`。
- `src/主调/主程序.cpp`：交互自检直接返回。
- `src/框架/游戏应用.h/.cpp`：
  - 鼠标左/右键按下沿检测；
  - 射线起点相机眼点、方向注视 - 眼点、最大 6 格；
  - 修改后重建目标区块；边界修改同步重建相邻区块。

## 四、验收口径

- Debug / Release 双配置构建零错误。
- `--interact-test` 与既有十四条自检均返回 0。
- `--self-test` 正常退出；未点击时世界不变。
- 射线方向复用相机方向约定。

## 五、风险与回退

- 只做体素级命中，不做三角形级检测。
- 放置不检查玩家碰撞，可能放入身体。
- 边界重建若性能异常，可先只重建目标区块。
