## 二、关键约定

- 方向：`前 = (-sin(yaw)cos(pitch), sin(pitch), -cos(yaw)cos(pitch))`；yaw 0 朝 -Z，yaw π/2 朝 -X。
- 第一人称：眼点 = 脚底 + 1.6，注视点 = 眼点 + 方向。
- 第三人称：注视点 = 脚底 + 1.4，眼点 = 注视点 - 方向 × 距离，按 8/s 指数平滑。
- 距离钳制 [1.5, 8.0]，视场角钳制 [30°, 110°]。
- F5 按下沿切换模式，按住不重复切换。

## 四、自检覆盖项

1. 默认模式为第一人称。
2. 偏航 0、俯仰 0 时注视方向为 -Z；偏航 π/2 时为 -X。
3. 俯仰 ±89° 时方向 Y 分量符号正确。
4. 第一人称眼高为脚底 + 1.6。
5. 第三人称注视高度 1.4，眼点在身后且距离为设置值。
6. 小步长平滑只靠近不越界。
7. 距离与视场角上下限钳制。
8. 模式切换往返正确。
