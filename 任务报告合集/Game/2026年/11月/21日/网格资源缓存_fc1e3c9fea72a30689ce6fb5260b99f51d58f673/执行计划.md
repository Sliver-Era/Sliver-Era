## 三、实现方式

1. `资源缓存`：`初始化` / `网格获取` / `网格释放` / `网格条目数` / `网格引用` / `关闭` / `自检`。
2. 键规范化：`\` → `/`，拒绝绝对路径与 `..`。
3. 程序化键 `@地面`、`@立方体`；资产键走 `资产路径` + `mesh_load_obj`。
4. 引用计数：获取 +1，释放 -1，归零卸载；下溢记录错误。
5. `游戏应用` 基线网格改用缓存；关闭顺序为释放引用 → 关闭缓存 → 关闭渲染器。
6. `--resource-test`：同键获取、分次释放、资产键、缺失资产。

## 四、分段执行

1. 缓存实现与键规范化。
2. 游戏应用接入。
3. OBJ 夹具。
4. 资源自检。
5. Debug / Release 构建与七条自检。
6. 提交与文档同步。

## 五、验收口径

- 双配置构建零错误。
- `--resource-test` 与其余六条自检均返回 0。
- 重复获取不重复加载；引用归零真正卸载。
- 不修改 `external/Engine` 版本锁，不新增外部库。
