# 执行计划 · 资产目录与路径规范（第 6 轮）

> 工作区：`Application/Game/Sliver-Era` ｜ 分支：main ｜ 计划时间：2026-11-21

## 一、开发任务

建立统一资产路径模块与目录规范，让配置、网格、材质、纹理、字体、关卡、存档、日志都按可执行文件目录解析，不依赖当前工作目录。

## 二、预修改文件

- `src/框架/core/资产路径.cpp`

修改：
- `src/框架/应用配置.h`、`src/框架/core/应用配置.cpp`
- `src/主调/主程序.cpp`
- `CMakeLists.txt`

## 三、实现方式

1. `可执行文件目录()`：`GetModuleFileNameW` + 按需扩容。
2. `资产路径()` / `存档目录()` / `日志目录()` / `目录确保()`。
3. `路径文本()` / `文本路径()` UTF-8 往返。
4. 主程序用资产路径解析配置；启动时创建 `saves/`、`logs/`。
5. `--path-test`：exe 目录、配置命中、缺失识别、中文往返、目录创建。
6. `assets/` 建立 config/meshes/materials/textures/fonts/levels。

## 四、分段执行

1. 路径模块。
2. 主程序与配置接入。
3. 目录结构与资产复制。
4. 路径自检。
5. Debug / Release 构建与六条自检。
6. 提交与文档同步。

## 五、验收口径

- 双配置构建零错误。
- 从任意当前工作目录启动，资产路径仍命中 exe 目录。
- `--path-test`、`--config-test`、`--self-test`、`--state-test`、`--module-test` 均返回 0。
- 不修改 `external/Engine` 版本锁，不新增外部库。
