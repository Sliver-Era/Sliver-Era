## 二、关键约定

- 事件链路：渲染层 UI 事件桥 → `Event_Broker` → `Focus_System` → `Input_Manager` → 游戏查询。
- 端口绑定顺序：先 `Broker_Attacher` / `Evt_Sender`，再 `attach()`；否则订阅登记发送失败。
- `Input_Manager` 构造时已生成密钥，外部拿不到；对象创建与焦点事件必须由游戏侧终端发送。
- 输入对象名固定为「玩家」，映射 W/S/A/D/SPACE/ESCAPE，鼠标 X/Y 为位移型轴（scale 0.002，clamp 0.2）。
- 焦点在 `frame_begin()` 后生效，初始化末尾立即调用一次。
- 固定更新顺序：模块调度 → 输入帧首 → 玩家控制 → 实体组件更新。

## 四、复开发路径

1. 新增输入对象时沿用游戏侧终端发送 `Input/Create`，不要另建中转器。
2. 查询键位用 `key_held_get`，查询视角增量用 `object_axis_value_get`；不要直接读平台状态。
3. 移动方向必须与 `玩家组件` 的偏航约定一致：前 = (-sin, 0, -cos)，右 = (cos, 0, -sin)。
4. 关闭顺序：先把玩家置空、清实体、关缓存、退出输入，最后关闭渲染器。
