# 执行计划 · 输入层接入焦点与映射系统（第 14 轮）

> 代码推送哈希：`2323522070730f083bf0f2ddc6efd87f7c263ce1` ｜ 类型：方向深研轮（游戏框架搭建 / 阶段 D）

## 一、目标

把引擎输入链路接入游戏：渲染层原始输入 → 焦点系统 → 输入管理器 → 游戏查询，
建立「玩家」映射对象与焦点，并驱动玩家移动、跳跃与视角。

## 二、分段执行

### 阶段 1：游戏输入四件套

- 新增 `src/输入/游戏输入.h` / `core/游戏输入.cpp`：
  - 成员：`Event_Broker`、游戏侧 `Event_Terminal`、`Focus_System`、`Input_Manager`；
  - 端口绑定工具：`Broker_Attacher` → `broker.attach`，`Evt_Sender` → `broker.receive`。

### 阶段 2：接入与对象创建

- `初始化`：
  1. 绑定渲染层 `input_event_terminal()` 端口并 `input_system_attach()`；
  2. 游戏终端生成密钥、绑定、attach；
  3. 焦点系统与输入管理器绑定、attach；
  4. 以 `Input/Create` 创建「玩家」（W/S/A/D/SPACE/ESCAPE，鼠标 X/Y 位移轴）；
  5. 以 `Input/MouseFocus` 转移焦点，并立即 `frame_begin()`。
- 对外接口：`可用 / 帧首 / 键按住 / 轴值 / 主对象获取 / 关闭`。

### 阶段 3：玩家控制与自检

- `游戏应用`：渲染器初始化后接入输入；固定更新顺序改为模块 → 输入帧首 → 玩家控制 → 实体组件。
- `player_control`：WASD 按偏航合成水平速度（对角归一化 5 m/s）、SPACE 跳跃、鼠标位移驱动视角。
- `--input-test`：隐藏窗口校验输入可用、主对象「玩家」、W 未按住。

## 四、验收口径

- Debug / Release 双配置构建零错误。
- `--input-test` 与既有十二条自检均返回 0。
- 主对象为「玩家」，输入管理器可用；关闭顺序先退出系统输入再关闭渲染器。

## 五、风险与回退

- 终端端口必须先绑定再 attach，否则订阅事件发送失败。
- `Input_Manager` 构造时已生成密钥，外部不可再取；必须用游戏侧终端发送对象创建与焦点事件。
- 焦点在首帧前不生效，初始化末尾必须 `frame_begin()`。
