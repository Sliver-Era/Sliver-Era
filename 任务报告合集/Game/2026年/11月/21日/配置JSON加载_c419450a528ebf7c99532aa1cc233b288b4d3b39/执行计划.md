## 一、开发任务

把窗口、渲染、相机、场景参数落成 JSON 配置，建立「默认值 → JSON → 命令行」覆盖链，并加配置自检。

## 二、预修改文件

- `src/框架/应用配置.h`、`src/框架/core/应用配置.cpp`
- `src/主调/主程序.cpp`
- `CMakeLists.txt`
- 新增 `assets/config/游戏配置.json`、`assets/config/非法配置_测试.json`

## 三、实现方式

1. `配置加载`：读取 JSON，按窗口/渲染/相机/场景四组覆盖默认值。
2. 字段校验：范围、数组长度、类型、近远平面关系；非法回落默认值并记录警告。
3. `配置路径解析`：预扫描 `--config`；主程序按 exe 目录生成默认路径。
4. `配置自检运行`：默认配置、缺失文件、非法值三项。
5. CMake 构建后复制 `assets/` 到可执行文件同目录。
6. 中文路径用 `u8"..."` 构造 `std::filesystem::path`。

## 四、分段执行

1. schema 与加载器。
2. 非法值归一与警告。

4. 资产复制与默认配置。
5. Debug / Release 构建与自检。
6. 提交与文档同步。

## 五、验收口径

- 双配置构建零错误。
- `--config-test`、`--self-test`、`--state-test`、`--module-test` 均返回 0。
- 命令行覆盖 JSON 的结果可观测。
- 不修改 `external/Engine` 版本锁，不新增外部库。
