# 执行计划 · EngineSystem 机制对齐（内嵌 bullet3）

> 用户裁定：bullet3 为内部使用库，直接内嵌进源码编入 `EngineSystem.lib`，不单独产库、不暴露独立目标。

## 一、目标

1. bullet3（LinearMath + BulletCollision）源码直接编入 `EngineSystem.lib`，`src/collision` 由此获得符号；
2. 源文件收集改为与 EngineFoundation 同一口径：整目录 GLOB（`src/*.cpp` + `common/*.cpp`），删除模块白名单与死过滤规则；
3. 头快照镜像范围改为 `common + src`（覆盖 collision 公共头）；
4. 锚点哈希额外覆盖 `external/bullet3/src`，弥补“第三方头变了但锚点不变”的缺口；
5. 补齐 EngineSystem 缺失的归档 BOM 包装与 install 规则；
6. 同步注释与 README。

## 二、分段

### 段 A：脚本扩展
- `Engine/EngineFoundation/cmake/生成版本锚点.cmake` 新增可选参数 `HASH_DIRS`：
  为空时沿用 `MIRROR_DIRS`；非空时只用于计算哈希，不影响快照镜像范围。

### 段 B：EngineSystem/CMakeLists.txt
- 头部注释对齐 Foundation（预设用法、产物、依赖、契约）。
- 第 1 节修正过时的“时间戳最新探测”描述。
- 源文件收集：`src/*.cpp` + `common/*.cpp`；登记 `src`、`common`；删除 `/Tests/`、`/src/gui/Config_Editor/` 过滤与相关注释。
- 新增 3.1 节：GLOB `external/bullet3/src/{LinearMath,BulletCollision}/*.cpp`，以 `target_sources` 编入；注册配置依赖；MSVC 下对这些源单独 `/W3`。
- 锚点命令追加 `-DHASH_DIRS=...common;...src;...external/bullet3/src`。
- 快照 `MIRROR_DIRS` 改为 `Engine/EngineSystem/common;Engine/EngineSystem/src`。
- 新增归档 BOM 包装（复用 Foundation 的 `ar_rsp_bom.ps1`）。
- 新增 install 规则（头 + 库，口径同 Foundation）。

### 段 C：文档
- `cmake/对外接口.cmake`：更新“bullet3 尚未接入”的备注。
- `README.md`：第三方依赖表改为“bullet3 已编入本层”；构建机制补充整目录 GLOB、内嵌 bullet、锚点范围。

### 段 D：验证
- EngineSystem Debug + Release 构建零错误；`EngineSystem.lib` 含 `btCollisionWorld` 等符号与 `byjy_stamp_engine_system_*`。
- Foundation / Renderer 不重建也应不受影响；Test 配置通过、`TestGui` 通过。
- 全量 Test 仍受陈旧碰撞用例阻塞（另有旧路径问题），本轮不修。

## 三、风险

- collision 首次参与编译，可能存在未暴露的编译错误；按最小修改原则处理并在报告中记录。
- 内嵌后 Game 无需新增库；`silver_era` 的旧 `EngineSystem.lib` 不含碰撞符号，但 Game 未调用碰撞，暂不受影响。
- 锚点哈希范围扩大后，bullet 头任何变化都会要求重建本层，属预期。
