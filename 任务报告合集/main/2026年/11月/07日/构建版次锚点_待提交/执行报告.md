## 二、机制口径

- 锚点符号名：`byjy_stamp_<层>_<12 位哈希>`；层标识分别为 `engine_core` / `renderer` / `engine_system`。
- 哈希输入：镜像目录内全部公共头（相对路径 + 内容，按路径排序）+ 构建类型 + 运行库口径（Debug→MDd，其余→MD）。
- 锚点头随快照发布；上层不需要显式包含，由导入目标强制前置包含。
- 快照目标依赖本层库：库构建失败时保留旧快照，不会出现「新头 + 旧库」。
- `EngineCore` / `Renderer` / `EngineSystem` 三层都已产出锚点；聚合层与 Test 无需改动业务头。

## 四、发现的问题

1. **Test 层陈旧用例**（非本次改动引入）：`src/单元测试/EngineCore/核心/碰撞*测试.cpp`、`坐标类型测试.cpp` 仍引用
   `Engine/EngineCore/src/core/spatial/collision/...` 与 `.../spatial/common/core/坐标类型.h`，这些头已随碰撞模块迁往
   EngineSystem（`Engine/EngineSystem/src/collision`，且尚未并入 EngineSystem 编译）。旧构建树能编过是因为其快照来自迁移前的旧源码树；
   本次从零重建后暴露。需单独立项：迁移用例路径 + 让碰撞模块进入 EngineSystem 编译并产出 bullet3 符号。
2. **渲染层归档包装器路径失效**：`EngineSystem/src/core/Renderer/CMakeLists.txt` 仍用 `../../Engine/EngineCore/...`，
   渲染层迁入后该路径不存在，导致中文对象名归档 LNK1181。已改为上溯五级。
3. **旧路径构建树**：`Engine/*/out/build`、`Application/Test/out/build` 的缓存全部指向已不存在的
   `D:/代码存储/代码仓库/白银纪元`，已整体删除并重建（约 2.7 GB 失效产物）。
4. **Game 与 Editor 尚无锚点**：两者不走接入函数，`silver_era` 冻结副本中的头不带锚点头，暂不受保护；后续可让 Game 消费带锚点的快照。

## 五、限制

- 跨层锚点只覆盖 `EngineCore` / `Renderer` / `EngineSystem`；Test 自有用例头不对外发布，无需锚点。

- 保留覆盖变量 `BYJY_*_LIB_PATH`：手工接另一棵树的库时，若锚点哈希不同会立即报错，这是预期行为。
