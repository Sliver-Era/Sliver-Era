## 一、完成内容

1. **系统输入对齐**：渲染层把 SDL 扫描码 / 鼠标 / 滚轮翻译为系统中立键位位域，构造含 `held` 权威快照的 `Input/Raw`，经自有事件终端投递给焦点系统；UI 文本框获焦时携带 `text_mode` 挂起游戏键位映射。

3. **缺陷修复**：索引基址与顶点基址分离、像素→NDC 的 Y 方向、UI 阶段改为独立无深度通道。

## 四、关键口径

1. **键位翻译**（与系统层报告表一致）：
   - 字母 A~Z → 主键盘 1~26；数字 0~9 → 27~36；符号 37~47；
   - 控制 / 功能 / 导航 / 修饰 → 控制类对应编号（LSHIFT=34 … RGUI=41）；
   - 小键盘、鼠标 1~5、滚轮上/下 → 各自键类。
2. **Raw 载荷**：`keys` 只投放按下 / 抬起沿（重复沿不产生语义命令）；鼠标按键与滚轮同样以边沿形式投放；滚轮每齿投「按下＋抬起」一对，避免污染系统按住集合；`held` 为键盘 + 鼠标按键的权威快照。
3. **文本模式**：UI 文本框获焦时 `text_mode=true`，系统侧 `object_map` 挂起键位映射但继续跟踪物理按住状态。
4. **UI 绘制阶段**：单采样与 MSAA 均在场景 pass 结束后另起「仅颜色附件、载入保留」的通道；UI 管线固定 `depthAttachmentFormat=UNDEFINED`、关闭深度测试、单采样、Alpha 混合。
5. **像素坐标**：Vulkan NDC y 向下，矩阵为 `x'=2x/W-1`、`y'=2y/H-1`，不做 Y 翻转。
6. **绘制记录**：`first_index` 取索引基址（不是顶点基址）；每条记录携带控件裁剪矩形，录制时转为 scissor，结束后恢复全屏。

构建环境备注：

- MSVC 偶发 `D1090/C1090 PDB API` 失败：`TMP`/`TEMP` 必须为纯 ASCII 目录，必要时删除对应 `CMakeFiles/<目标>.dir/<目标>.pdb` 后重试；
- 测试层着色器 `.spv` 为配置期拷贝，改渲染层着色器后需重配/重建测试层。

## 六、已知边界

1. 未向焦点系统发送 `MouseFocus` / `ModalPush` / `ModalPop`；UI 弹窗与游戏让焦尚未接线。
2. UI 输入仍以渲染层本地快照为准；系统焦点/文本模式不反向驱动 UI 焦点。
3. 文本编辑无选区、剪贴板、Home/End、IME 候选窗定位；预编辑串仅在快照中保留。
4. 无圆角 / 边框样式系统、无布局引擎、无滚动容器；按钮标签与文本框为单行。
5. 多窗口仍是单焦点实例。
