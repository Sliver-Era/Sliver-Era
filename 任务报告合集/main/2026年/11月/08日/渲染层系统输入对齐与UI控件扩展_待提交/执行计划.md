# 执行计划：渲染层系统输入对齐与 UI 控件扩展

> 版次：本地未提交（`_待提交`）
> 工作区：`白银纪元`；改动层：`Engine/EngineRenderer`、`Application/Test/tests/Renderer`
> 日期：2026-11-08

## 一、目标

1. 对齐 `EngineSystem` 新的输入体系：键位位域、组合修饰、`held` 权威快照。
2. 继续原生 UI：补常用控件、焦点导航与裁剪。

## 二、分段

### 阶段 A：系统输入对齐

- 新增 `Input/系统输入桥.h` 与 `core/系统输入桥.cpp`：
  - `Key_Code`（SDL 扫描码）→ `Input_Key` 位域（main / control / keypad / mouse / wheel）；
  - 鼠标按键、滚轮方向 → 系统键位；
  - `Input_Frame` → `Input/Raw` 载荷（`frame` / `dt` / `keys` / `held` / `pointer` / `text_mode`）。
- 渲染器持有 `Event_Terminal`，新增 `input_event_terminal()` / `input_system_attach()` / `input_system_detach()` / `input_system_attached()`；每帧投递 Raw。
- 文本模式门控：UI 文本框获焦时 `text_mode=true`，系统侧挂起游戏键位映射。
- 验收：键位翻译与载荷字段用例；真实中转站 + 焦点系统 + 输入管理器的端到端命令产出。

### 阶段 B：UI 控件扩展

- 新增 `Label` / `Checkbox` / `Slider` 控件与对应读写 API。
- Tab / Shift+Tab 焦点导航（按钮 / 文本框 / 复选框 / 滑动条）；Enter / 空格键盘激活。
- 焦点环绘制；逐控件 `scissor` 裁剪（文本溢出被裁）。
- 滑动条按下 / 拖拽更新取值并回调。
- 验收：复选框点击切换、滑动条拖拽、Tab 焦点导航、标签绘制与裁剪。

### 阶段 C：缺陷修复（对齐过程暴露）

- 索引基址与顶点基址分离（`vkCmdDrawIndexed.firstIndex` 必须取索引基址）。
- 像素 → NDC 矩阵按 Vulkan「NDC y 向下」口径，去掉多余的 Y 翻转。
- UI 阶段单采样与 MSAA 统一改为「场景 pass 结束后另起无深度颜色通道」，消除 UI 管线与场景深度附件格式不匹配。

### 阶段 D：验证与收口

- Renderer Debug / Release 构建；Test Debug 构建。
- 新增套件全跑；渲染层全量回归。
- 写执行报告，清理临时产物。

## 三、验收口径

| 项目 | 判据 |
| --- | --- |
| 输入对齐 | 渲染层构造的 Raw 能被系统链路解析并产出 `Move` 命令 |
| UI 控件 | 复选框状态切换、滑动条取值、Tab 焦点切换、标签裁剪均通过 |
| 回归 | `Renderer*` 全量通过，无新增失败 |
