## 五、frame_render 阶段提取（`Renderer/core/渲染器_帧阶段.cpp`）

### 做法

阶段函数一律为**自由函数**，首参 `Renderer_Impl_Holder::Impl* impl`，函数体**原样保留 `impl->` 前缀**，只把 `Impl::` 常量补成全限定名。

### 为什么不用成员函数

第一轮曾把块搬成 `Impl` 成员函数并去掉 `impl->` 前缀，结果 `Renderer_Decode_Test` 在纹理图像创建后永久阻塞、回退即恢复。原因是去掉前缀后，块内同名局部量会静默接管成员访问。改用 `Impl*` 传参后同一套件 1.4 秒通过，此路径已验证。

### 抽取清单

| 阶段函数 | 作用 | 返回失败 |
| --- | --- | --- |
| `frame_stage_input_events` | 泵事件 + 输入锁存 + 原生 UI 交互 | 否 |
| `frame_stage_shadow_matrices` | 光源空间矩阵与级联拟合 | 否 |
| `frame_stage_spot_shadow_matrices` | 聚光阴影矩阵与瓦片选择 | 否（返回有效标志） |
| `frame_stage_shadow_pass` | 阴影 pass（按需重绘） | 是 |
| `frame_stage_scene_ubo` | 场景 UBO 组装与上传 | 是 |
| `frame_stage_descriptor_sets` | 描述符集与实例缓冲句柄填装 | 否 |

`frame_render` 保留：窗口尺寸 / 交换链重建 / 帧槽获取 / 实例缓冲写入 / 后处理与天空项追加 / 命令录制 / 提交呈现 / 回读。

### 配套

`渲染器_帧内部.h`：把 `batch_adjacent_items`、`shadow_signature_build` 由匿名命名空间改为命名空间内 `inline`，供帧渲染与帧阶段两个 TU 共用。
