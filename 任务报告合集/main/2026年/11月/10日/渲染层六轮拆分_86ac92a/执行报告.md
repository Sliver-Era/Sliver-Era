# 渲染层六轮拆分：初始化阶段函数化 · 执行报告

> 代码版次：`Engine/EngineRenderer` `86ac92a`（上游 `da54b9a`）  
> 测试版次：`Application/Test` `16bf11b`

## 一、目标

拆掉渲染层最后一个大函数 `Renderer_Core::init`（27.6 KB / 619 行）。为守住「约 50 处回退路径」的行为，先补失败注入用例，再把各阶段抽成自由函数在 `init` 内顺序调用。

## 二、变更

### 2.1 先补回滚契约用例（796 → 799）

`tests/Renderer/src/渲染着色器校验测试.cpp` 追加三条，失败点选在第 ⑩ 步（着色器加载），其前已完成平台 / 实例 / 设备 / 表面 / 内存 / 交换链 / 帧 / 着色器模块，正好覆盖这八步的逆序回滚：

| 用例 | 断言 |
| --- | --- |
| `着色器失败后回滚契约` | 六项资源计数归零、交换链尺寸归零、`frame_render()` 返回假、`shutdown()` 连调两次不崩 |
| `着色器失败后可重新初始化` | 失败一次后仍能成功 init、能推进一帧、关闭后还能再 init |
| `失败成功交替不残留` | 三轮「失败 → 成功 → 一帧 → 关闭」循环，每轮都断言状态 |

### 2.2 init 拆为五个阶段函数

`src/render/Renderer/core/渲染器_初始化.cpp` 只保留：实现体与重复 init 检查、宽高与在途帧数校验、`effective` 生成、五次阶段调用、配置记录与开关落位、⑳ 阴影资源、完成日志。

```cpp
if (!renderer_init_platform(self_ptr, impl.get(), effective))            return false; // ①–⑤
if (!renderer_init_memory_swapchain(self_ptr, impl.get(), effective))    return false; // ⑥⑦
if (!renderer_init_frame_shader_pipeline(self_ptr, impl.get(), effective)) return false; // ⑧–⑪
if (!renderer_init_graphics(self_ptr, impl.get(), effective))            return false; // ⑫–⑭（五轮已抽）
if (!renderer_init_services(self_ptr, impl.get(), effective))            return false; // ⑮–⑱
if (!renderer_init_ui(self_ptr, impl.get(), effective))                  return false; // ⑲
```

改写仅三条机械变换：`self().` → `owner->`、`impl.get()` → `impl`、块内 `Impl::` 补全限定名；`impl->` 前缀与函数体其余代码原样保留（沿用「成员函数化去前缀会与同名局部量冲突」的教训）。

`渲染器实现访问.h` 追加 6 个友元，因为 `渲染器_初始化_服务.cpp` 的 `text_host` 回调 lambda 与事件转发 lambda 在自由函数作用域内需要访问 protected 的 `impl`；`text_host.user` 由 `this` 改为 `owner`。

## 四、踩坑

1. **友元缺口**：阶段函数内的 lambda 捕获 `impl` 后访问 `Renderer_Impl_Holder::Impl`，在自由函数里不再是成员上下文，`protected` 直接被拒。补 `friend` 声明解决。
2. **`this` 逃逸**：`text_host.user = this;` 在自由函数里 `this` 是 `Renderer*` 之外的语义，改为 `owner`。
3. **一次不可复现的挂起**：拆分后首次全量回归在 `Renderer_Scene_Test.环境光抬升背光面` 处日志停滞 25 分钟、CPU 持续上涨，进程被手动终止。随后两次独立全量回归均 799/799 通过（单测独跑该用例、独跑 Scene 全套 176 例亦通过），判断为一次性环境抖动（校验层 / 驱动），未在代码侧留改动。
4. **gtest XML 输出路径**：`--gtest_output=xml:<中文路径>` 在本地码页下会 `Unable to open file` 并 `FATAL` 退出（用例本身已全部跑完）。中文路径不用于 gtest 输出。
