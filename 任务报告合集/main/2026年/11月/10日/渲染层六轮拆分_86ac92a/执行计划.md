## 三、执行分段

### 第一段：失败注入用例

在 `渲染着色器校验测试.cpp` 追加三条，锁住「失败 → 回滚 → 可重来」的契约：

1. `着色器失败后回滚契约`：资源计数全零、交换链尺寸零、`frame_render` 拒绝、`shutdown` 幂等。
2. `着色器失败后可重新初始化`：失败一次后能成功 init 并推进一帧。
3. `失败成功交替不残留`：三轮「失败 → 成功 → 关闭」。

失败点选在第 ⑩ 步（着色器加载），其前已完成平台 / 实例 / 设备 / 表面 / 内存 / 交换链 / 帧，正好检验这八步的逆序回滚。

### 第二段：init 阶段函数化

沿用已确立的安全模式：**自由函数 + 首参 `Renderer_Impl_Holder::Impl*` + 保留原始 `impl->` 前缀**。

签名统一为：

```cpp
bool renderer_init_xxx(Renderer* owner, Renderer_Impl_Holder::Impl* impl, Renderer_Config& effective);
```

改写规则仅三条：`self().` → `owner->`、`impl.get()` → `impl`、块内 `Impl::` 补全限定名。函数体其余代码不动。
