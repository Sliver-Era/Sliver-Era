# 渲染层七轮门面拆分：单类 `Renderer` → 六域子渲染器 · 执行计划

> 代码版次：`Engine/EngineRenderer`（上游 `86ac92a`）
> 工作区：`D:\代码仓库\白银纪元`　工作站：`D:\agent\working_station\silver_era`
> 用户决策：方案 B（六域子渲染器）；每阶段必须全绿；不做长期兼容壳；彻底删除共享 `Impl`。

## 一、背景与目标

`Renderer` 现为单一聚合类：虚继承 14 条能力接口、共 **349 个公开方法**，全部方法共享同一个 `Impl`（8 个聚合子结构、约 300 个成员）。域边界只靠命名约定，任一方法都能读写其它域的状态。

目标：

1. 拆成 **6 个域子渲染器**，每个域持有自己的状态与资源；
2. 根 `Renderer` 只做「持有 + 装配 + 持有生命周期入口」，不再承载域方法；
3. 删除共享 `Impl` 与 14 路虚继承，跨域访问只走显式的窄上下文或域公开接口；
4. 同步迁移全部调用点，不保留 349 方法转发壳。

## 二、目标架构

### 2.1 六个域与方法归属（合计 349）

| 域类 | 收编的接口 | 方法数 | 职责 |
| --- | --- | --- | --- |
| `Render_Device` | `Renderer_Core`(14) + `Renderer_Output`(16) | 30 | 平台 / 设备 / 交换链 / 帧推进 / 统计 / 窗口尺寸与 MSAA-SSAA |
| `Render_Resource` | `Renderer_Mesh`(25) + `Renderer_Texture`(24) + `Renderer_Material`(22) + `Renderer_Pipeline`(4) | 75 | 网格 / 纹理 / 材质 / 具名管线与着色器模块 |
| `Render_Scene` | `Renderer_Scene`(32) + `Renderer_Lighting`(49) + `Renderer_Style`(21) | 102 | 相机 / 场景装配 / 光源 / 阴影参数 / 雾 / 风格开关 |
| `Render_Compute` | `Renderer_Compute`(53) | 53 | 计算缓冲与管线 / Hi-Z / 簇划分 / GPU 剔除 / 间接绘制 |
| `Render_Particle` | `Renderer_Particle`(32) | 32 | 粒子容量 / 发射器 / GPU 推进 / 绘制 / 压缩 |
| `Render_Ui` | `Renderer_Ui`(8) + `Renderer_Text`(13) | 21 | UI 通道 / 输入桥 / 字体 / 文字绘制 |

根 `Renderer`：构造 / 析构 + `device()` / `resource()` / `scene()` / `compute()` / `particle()` / `ui()` 六个访问器 + **14 个生命周期方法**（`init` / `shutdown` / `valid` / `frame_render` / `close_requested` / `frame_count` / `frame_stats_get` / `frame_wait_idle` / `frame_stats_reset` / `resource_counts` / `scene_upload_bytes` / `instance_upload_bytes` / `shadow_readback` / `light_fill_set`），全部为一行转发到 `Render_Device`。

> 保留 14 个生命周期入口的理由：调用点 1484 处（`init` 754 + `frame_render` 730），且语义上属于"根"而非"设备域"。这不构成 349 方法的转发壳。**【待确认 1】**

### 2.2 共享上下文

删除 `Impl` 后，跨域只保留一个**只读**上下文：

```cpp
struct Render_Core_Context
{
    Platform_Context& platform;
    Device_Context&   device;
    Memory_Context&   memory;
    Swapchain_Context& swapchain;   // 尺寸按帧刷新，域内只读
    Frame_Context&    frame;        // 帧环与命令缓冲
    const Renderer_Config& config;
};
```

`Render_Device` 独占持有上述模块实例并负责其生命周期；其余五域构造时接收 `Render_Core_Context&`，不得持有可变引用。

### 2.3 依赖方向

```
Renderer（容器）
   ├─ device()    → Render_Device      ← 持有 Core_Context + 其余五域的裸指针
   ├─ resource()  → Render_Resource    → Core_Context（只读）
   ├─ scene()     → Render_Scene       → Core_Context（只读）
   ├─ compute()   → Render_Compute     → Core_Context（只读）
   ├─ particle()  → Render_Particle    → Core_Context（只读）
   └─ ui()        → Render_Ui          → Core_Context（只读）
```

`Render_Device::frame_render` 按现有阶段顺序调用其余域的公开方法（场景 UBO / 描述符集 / 阴影 / HiZ / 簇 / 粒子推进 / UI 绘制 / 后处理链），依赖由根装配时注入。

## 三、状态归位规则

现有 8 个 `实现体_*.h` 与域**不对齐**，归位按下述规则（冲突项在执行报告中逐条记录）：

| 规则 | 内容 |
| --- | --- |
| R1 | 成员归属 = 其生命周期管理者。谁创建、谁销毁、谁重置，就归谁。 |
| R2 | 只读消费方通过 `Render_Core_Context` 或持有者域的 `const` 接口读取，不保留指针副本。 |
| R3 | 同一份数据被两域写：先判定唯一写者，另一域改为调用写者接口（如阴影参数由 `Render_Scene` 写、`Render_Device` 读）。 |
| R4 | 纯配置项（`Renderer_Config` 及其派生生效值）归 `Render_Device`，经上下文只读暴露。 |
| R5 | 帧内暂存（`pending_items` / scratch 向量）归实际录制者 `Render_Device`。 |

已知需要判定的纠结点（执行时按 R1–R5 逐条定）：

- `bound_view` / `bound_sampler`：纹理、材质、渲染目标、后处理共用 → 归 `Render_Resource`，后处理经接口设置；
- `shadow_*` 全族（约 40 项）：开关与参数归 `Render_Scene`，阴影目标与 pass 资源归 `Render_Device`；
- `post_*` / `ssaa_*` / `present_target`：归 `Render_Device`（帧编排），渲染目标句柄由 `Render_Resource` 管理；
- `particle_*` 全族（约 50 项）+ 粒子用计算缓冲/管线：归 `Render_Particle`，`Compute` 只提供通用缓冲与派发；
- `material_*` 全族：归 `Render_Resource`，但 PBR/Toon 全局参数量与 `Render_Scene` 的风格开关同源，需先统一写者；
- `instance_*` / `cull_*`：实例缓冲与剔除归 `Render_Device`，GPU 剔除归 `Render_Compute`。

## 四、调用点迁移

| 类别 | 数量 | 迁移方式 |
| --- | --- | --- |
| 域方法调用 | 约 3,900 处 / 50 文件 | 按方法名映射：`X.mesh_draw(` → `X.resource().mesh_draw(`；`X.scene_apply(` → `X.scene().scene_apply(` |
| 生命周期调用 | 1,484 处 | 根保留，零改动（见 §2.1 待确认 1） |
| `self().` 门面内互调 | 323 处 / 18 文件 | 改为显式依赖：同域内 `this->`，跨域走持有指针 `owner->scene().xxx()` |
| 类型声明 | 50 文件 `engine::Renderer` | 仅当访问域方法时补访问器，类型名不变 |

迁移以方法名前缀为唯一依据（`mesh_`/`texture_`/`material_`/`pipeline_`/`camera_`/`scene_`/`light_`/`shadow_`/`fog_`/`post_`/`render_target_`/`compute_`/`hiz_`/`cluster_`/`gpu_`/`particle_`/`text_`/`font_`/`ui_`/`input_`/`ssaa_`/`msaa_`/`window_`/`extent_`），不按变量名匹配，避免误伤非渲染器对象。
