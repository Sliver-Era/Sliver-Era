## 一、计划

- 目标：GGX 法线分布支持切向 / 副切向不同粗糙度（头发、拉丝金属）；强度 0 时退化为各向同性；默认关闭。
- 分段：`Scene_State` 增 `pbr_aniso` / `pbr_aniso_strength` ＋ 门面；场景 UBO 尾追加 `pbr_aniso`（992 浮点 / 3968 字节）；着色器 `ggx_specular` 增加各向异性分布；用例两例。
- 验收：关闭态逐字节不变；强度 0 与各向同性等价（≤2 级）；强度 0.8 高光可区分。

## 二、交付

- 门面 `pbr_aniso_set` / `pbr_aniso`、`pbr_aniso_strength_set` / `pbr_aniso_strength`（强度 0..1，越界整次忽略）。
- UBO 尾追加 `vec4 pbr_aniso`（x 开关、y 强度）；`SCENE_BLOCK_FLOATS` 988 → 992（3952 → 3968 字节），两处描述符范围与契约常量同步。
- `ggx_specular` 各向异性分支：切线 = 世界 X 投影到切平面（v1 全局轴向），`at = α(1+s)`、`ab = α(1−s)`，
  `D = 1 / (π·at·ab·((T·H)²/at² + (B·H)²/ab² + N·H²)²)`；几何项仍用各向同性 Smith-Schlick（已知简化）。
