# 各向异性 GGX（方向九第 722 轮）· 执行计划

> 日期：2026-11-17
> 前置：721 光泽度映射修正（阶段 C 收口）。

## 目标

GGX 法线分布支持切向 / 副切向不同粗糙度（头发、拉丝金属）；强度 0 退化为各向同性；默认关闭。

## 分段

- A：`Scene_State` 增 `pbr_aniso` / `pbr_aniso_strength` 与门面。
- B：场景 UBO 尾追加 `pbr_aniso`（992 浮点 / 3968 字节），描述符与契约常量同步。
- C：`ggx_specular` 增加各向异性分布分支（世界 X 投影切线，v1 全局轴向）。
- D：用例：强度 0.8 高光可区分；强度 0 与各向同性等价；越界强度忽略。

## 验收

- 关闭态逐字节不变；强度 0 差异 ≤ 2；强度 0.8 差异像素 > 0；PBR 与环境套件全过。
