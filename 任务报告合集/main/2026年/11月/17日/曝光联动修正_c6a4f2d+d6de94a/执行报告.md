## 一、背景

737 轮同题用例实测 EV −2 / 0 / +2 → **165 / 100 / 100**，非单调，当时判定为真实口径问题并回退。
本轮回溯发现：**是用例缺陷，不是引擎缺陷**。

## 二、根因

- 绘制项按帧提交、跨帧不保留：737 只在首帧登记了四边形绘制，后两帧只剩清屏色
  （清屏色经 ACES 后约 100，故 0 与 +2 两档相同）。
- 修正：`frame_at` 内每帧重新 `mesh_draw` 后再 `frame_render`。

## 四、口径与实测

- EV −2 中心 **165**、EV 0 **232**、EV +2 **232**（8 位场景目标在 EV ≥ 0 已饱和）；
