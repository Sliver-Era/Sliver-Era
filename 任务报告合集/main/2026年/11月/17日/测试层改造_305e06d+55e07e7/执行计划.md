# 测试层改造 · 执行计划

> 日期：2026-11-17（12:30 常规窗口，终点 17:10）
> 依据：2026-11-16 测试层评估结论——测试锁定「当前实现取值与门面形状」，新增功能易触发多文件改动。
> 目标：降低测试维护成本，不改变渲染行为、不改变通过用例的断言强度。

## 一、总目标

1. 公共测试前提收敛为共享夹具库，消除按文件复制的 `hidden_config` / `pixel_get` / 几何构造。
2. 实现常量（UBO 尺寸、实例步长、默认资源计数、光源槽上限）集中到契约探针，功能用例只断言行为。
3. 纯数据逻辑（光照选择/优先级、簇划分、关卡文本等）以无 GPU 单测覆盖，减少 E2E 依赖。
4. 像素断言统一为结构化指标（亮度、差异像素数、压暗像素数），不再各自维护逐字节判据。

## 二、分段与验收

### 阶段 A：共享夹具库

- 新增 `Application/Test/tests/Renderer/src/测试辅助/渲染测试辅助.h`：
  - 窗口配置：`hidden_config()`、`msaa_config(samples)`
  - 像素：`pixel_bytes()`、`pixel_get()`、`pixel_text()`、`outer_max()`
  - 几何：`quad_data()`、`quad_data_with_normal()`、`cube_data()`、`triangle_data()`
  - 纹理：`solid_red()`、`solid_white()`、`solid_gray()`
  - 矩阵：`full_screen_matrix()`、`rotation_y_matrix()`
  - 环境门控：`readback_ready(renderer)`（封装 `compute().readback_supported()` 与 `GTEST_SKIP`）
- 迁移 `渲染场景测试辅助.h`、`渲染后处理链测试辅助.h` 改为引用共享库；保留原函数名以免用例改动。
- 验收：TestRenderer Debug 构建零错误；场景 / 后处理链 / 光照 / 阴影套件全过。

### 阶段 B：契约探针收敛

- 新增 `Application/Test/tests/Renderer/src/渲染契约探针测试.cpp`，集中断言：
  - 场景 UBO 整块字节数与首帧整块上传
  - 每实例上传步长（112 字节）
  - 初始化后默认资源计数（纹理 2 / 管线 4 / 渲染目标 2）
  - 光源槽上限（前向 32 槽）与阴影段数基线
- 从 `渲染场景数据测试.cpp`、`渲染帧统计测试.cpp`、`渲染资源与链查询测试.cpp`、`渲染物体多材质测试.cpp`、`渲染着色器校验测试.cpp` 中移除重复的常量断言，保留行为断言。
- 验收：契约探针套件全过；上述五个套件行为断言不减。

### 阶段 C：纯数据层单测

- 新增 `Application/Test/tests/Renderer/src/渲染纯数据测试.cpp`（不建窗口、不建 GPU）：
  - 光照选择：声明顺序 / 重要性择优 / 同分同序 / 预算截断
  - 逐盏阴影优先级：降序取前 8 / 同分槽位升序
  - 簇划分：网格尺寸与簇计数关系、边界钳制
  - 关卡文本：已有 `渲染关卡测试.cpp` 覆盖，仅补未覆盖的默认值与拒绝分支（如适用）
- 前提：仅当内部头可被测试层直接 include 且不引入 Vulkan 类型；否则该子项降级为 E2E 并记录原因。
- 验收：新套件在无显示环境可跑通；渲染层源码零改动。

### 阶段 D：结构化像素断言

- 在共享辅助库中提供 `luma_of()`、`changed_pixels()`、`darkened_pixels()`、`brightened_pixels()`、`max_channel_diff()`。
- 迁移高改动频率的用例文件（场景数据 / 场景效果 / 光照 / 阴影 / 后处理链）改用共享指标；保留既有阈值与判据。
- 验收：迁移文件编译零错误、套件全过；断言语义与原实现一致。

### 收口

- 构建：TestRenderer Debug（必要时 Release）零错误。
- 回归：受影响套件全跑；窗口内全量回归一次。
- 报告：执行报告（文件清单、验证数据、用例数变化、未做项）。
- 文档：项目导航 Test 模块、两份汇总、能力汇总、下轮方向。
- 统计：运行 `检查/源码行数统计.ps1`。

## 三、风险与边界

- 只改测试层，不改渲染层源码；若发现必须改公共面，先记录并顺延到独立轮次。
- 迁移按套件分批，保证每批可独立构建；不做一次性 95 文件大搬迁。
- 逐字节断言不在本轮放宽，只把判据实现收敛到共享函数。
- 测试层着色器为配置期拷贝；本轮不新增着色器，无需重配（如新增则按既定流程重建 Renderer Release → 重配 Test）。
