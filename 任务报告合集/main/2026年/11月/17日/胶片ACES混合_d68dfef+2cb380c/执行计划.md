# 胶片与 ACES 的 look 混合（方向九第 742 轮）· 执行计划

> 日期：2026-11-17

## 目标

让胶片曲线与 ACES 之间可连续混合，供美术在「强光照亮部收束」上做连续调校，而不是二选一硬切。

## 分段

- A：`胶片色调映射.frag` 增加同口径 `aces()`，逐级额外四参槽 `.z` 作为混合比例（0 = 纯胶片，1 = 纯 ACES）。
- B：用例「胶片与ACES可混合」：纯胶片 / 混合 1.0 / 混合 0.5 / ACES 预设四帧对照。
- C：重建 Renderer 双树 → 重配 Test → 重建 Test → 后处理链全套 → 全量。

## 验收

- 混合 1.0 与 ACES 预设**逐字节一致**（最大通道差 = 0）；
- 纯胶片中心 < 0.5 中心 < ACES 中心；
- 0.5 画面既不等于胶片也不等于 ACES；
- 未设参（全 0）时与 739/741 逐字节一致。
