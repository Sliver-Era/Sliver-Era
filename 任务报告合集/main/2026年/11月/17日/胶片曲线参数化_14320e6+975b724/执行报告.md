## 二、用例口径

1. 默认帧（额外四参未设，恒 0）→ 中心应落 170–220（与 739 一致）；
2. `post_stage_extra_set(0, 4.0, 2.0, 0, 0)` → 白点变小、归一化分母变小 → 中心亮度上升 ≥ 8；
3. 上一步通道差 R−G ≤ 2；
4. `post_stage_extra_set(0, 0, 0, 0, 0)` → 与默认帧**逐字节相同**（最大通道差 = 0）。

## 三、踩坑与修正（重要）

- 首版把曲线参数放进**泛光参数槽**（offset 96）：未专设时该槽回落全局泛光参数（阈值 1.0 / 软膝 0.5），
  导致默认帧中心从 186 掉到 **120**，且「默认 vs 复位」差 66。
- 改为「逐级额外四参槽」（offset 128，默认恒 0）后语义干净，三帧全部符合预期。
- **第二个坑**：改完着色器后只跑 `cmake --build`，`Application/Test/shaders` 里的 `.spv` 仍是旧版
  （拷贝是配置期 `file(COPY)`），表现为「改了等于没改」。必须显式 `cmake -S <Test> -B <Test 构建目录>` 重配。
  → 该坑同时解释了 740 轮 Reinhard 的「首跑 188」，已在 740 报告中更正根因。
