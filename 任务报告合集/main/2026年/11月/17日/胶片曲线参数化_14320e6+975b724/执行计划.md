# 胶片曲线白点与曝光偏置可配（方向九第 741 轮）· 执行计划

> 日期：2026-11-17

## 目标

把 Hable 胶片曲线的两个关键旋钮（白点 / 曝光偏置）开放给调用方，用于强光照下的亮部收束调校；
未设参时与第 739 轮逐字节一致。

## 分段

- A：`胶片色调映射.frag` 的推送常量块增加「逐级额外四参槽」（offset 128）：x = 白点、y = 曝光偏置；
  参数 ≤ 0 时回落默认 11.2 / 2.0。
- B：用例「胶片曲线白点可配」：默认帧 / 白点 4.0 帧 / 复位帧三连对照。
- C：重建 Renderer 双树 → **显式重配 Test**（着色器为配置期拷贝）→ 重建 Test → 后处理链全套 → 全量。

## 接口选择

- 不使用泛光参数槽（offset 96）：未专设参数时该槽回落全局泛光参数（阈值 1.0 / 软膝 0.5），
  会与曲线参数语义冲突（实测默认帧被污染为 120）。
- 改用 `post_stage_extra_set`（offset 128；未设置时恒 0），语义干净。

## 验收

- 默认帧中心仍在 170–220；
- 白点 4.0 帧中心比默认高 ≥ 8，且通道差 ≤ 2；
- 复位后与默认帧逐字节相同；
- 后处理链 103 / 103；全量 0 失败。
