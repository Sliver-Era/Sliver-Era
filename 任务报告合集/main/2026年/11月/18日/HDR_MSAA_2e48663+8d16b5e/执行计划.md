# HDR 默认路径 MSAA 组合（方向九第 766 轮）· 执行计划

> 日期：2026-11-18
> 预期版次：Renderer `111c0f4 → 2e48663` / Test `218caa8 → 8d16b5e`

## 一、目标

HDR 默认路径的内部 16F 场景目标此前固定按单采样建立，导致 `msaa_samples > 1` 时 MSAA 在 HDR 路径静默失效。
本轮让场景目标跟随设备采样数建立多重采样附件，由链路径在场景 pass 结束时解析到单采样颜色。

## 二、分段执行

| 段 | 内容 |
| --- | --- |
| A | `hdr_scene_ensure(w, h, samples = 1)`：复用判据加入采样数；按采样数创建目标并记录 |
| B | 帧渲染传入 `state_ptr->msaa_samples`；`hdr_scene_destroy` / `output_reset` 复位为 1 |
| C | 新增用例 `HDR默认路径MSAA组合`：球体曲面轮廓上比较 1x 与 4x，帧统计采样数须为 4、链路仍为单级 |
| D | 收口：Debug ＋ Release 三套分片回归，两仓提交推送，工作站文档与导航新版次 |

## 四、判读口径

- 场景 pass / 解析 / 管线采样数均走既有链路径实现（`Frame_Render_Target.sample_count`、`parallel_plan`、`pipeline_rebuild`），本轮只补「目标建立时带上采样数」。
- 断言以 `frame_stats_get().msaa_samples`（= 场景目标采样数）与曲面边缘差异像素数为准。
- 平台 MSAA 上限不足 4 时用例自动跳过。
