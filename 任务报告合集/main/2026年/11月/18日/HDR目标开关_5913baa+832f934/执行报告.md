## 一、目标

把 752–755 验证过的 HDR 能力落成**可配置的引擎能力**：`Renderer_Config::hdr_targets` 开启后，
`resource().render_target_create` 默认产出 16F 目标；默认关闭，关闭时与引入前逐字节一致。

## 三、口径

- 只影响 `render_target_create`（默认格式入口）；含 `render_target_create_format` 的显式路径不变。
- 深度格式不变；16F 目标的渲染通道需格式匹配的管线变体（测试侧用 `pipeline_load_ex` 的 `color_format`）。
- 开关为**初始化期配置**，运行期只读查询；交换链重建与关闭均复位为关闭。

## 六、过程教训

- `渲染器_渲染目标.cpp` 内 `state_ptr` 指向**资源域状态**（`Resource_State`），不含设备域开关；应经 `owner->device().hdr_targets()` 读取，首次改动误用 `(*state_ptr).hdr_targets` 导致编译失败。
- Renderer 重建后聚合链接会报 `LNK2001 byjy_stamp_renderer_<hash>`（版本锚点 churn）：按「子测试树 → 聚合」顺序重链一次即可。
- Debug 与 Release 主工程都输出到 `Application/Test/EngineTests.exe`；跑完 Release 后需删掉该 exe 再重链 Debug，否则根目录留下的是 Release 版。
