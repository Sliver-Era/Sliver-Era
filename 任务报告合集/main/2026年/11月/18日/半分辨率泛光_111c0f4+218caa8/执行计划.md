# 自动泛光半分辨率（方向九第 765 轮）· 执行计划

> 日期：2026-11-18
> 预估版次：Renderer `5d62d11 → <新>` / Test `fe5d744 → <新>`

## 一、目标

给自动泛光链加一个**默认关闭**的半分辨率开关：提取 / 模糊两级在 1/2 边长目标上做，
叠加级仍按场景尺寸输出，泛光带宽度不变，中间层带宽与显存下降。

## 二、分段执行

| 段 | 内容 |
| --- | --- |
| A | `Renderer_Config.hdr_bloom_half_res`（默认 false）＋ 设备域状态落位 / 复位 |
| B | `hdr_bloom_ensure`：索引 0 / 1 取 1/2 边长（至少 1×1），索引 2 保持场景尺寸 |
| C | `hdr_bloom_frame_apply`：半分辨率下模糊半径按纹素折算（÷2 后钳回 1..4），否则泛光带会翻倍 |
| D | 新增用例 `HDR半分辨率泛光`：四级链仍成立、边界外有泛光、与全分辨率画面有可观测差异、主体亮度不变 |
| E | 收口：Debug ＋ Release 三套分片回归，两仓提交推送，工作站文档与导航新版次 |
