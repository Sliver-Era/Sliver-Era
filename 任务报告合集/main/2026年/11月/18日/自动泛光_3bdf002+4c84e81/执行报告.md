## 一、目标

让 HDR 默认路径「开箱即有泛光」：`hdr_auto_bloom` 开启时引擎自动挂四级链，
中间目标与管线自建；默认关闭，关闭时与 760 完全一致。

## 二、设计

- 配置：`Renderer_Config::hdr_auto_bloom`（默认 `false`），需 `hdr_targets` 同时开启。
- 引擎自建 3 个 16F 中间目标（提取输出 / 模糊输出 / 叠加输出）与 3 条 16F 管线
  （`亮部提取` / `模糊` / `泛光叠加`），末级复用默认色调映射管线（按 `hdr_tone_operator`）。
- 自动链：`亮部提取 → 模糊(半径 4) → 泛光叠加 → 色调映射`（链长 4，目标组 = 场景目标 + 3 中间目标）。
- 介入条件：`hdr_targets && hdr_auto_bloom && present_target == 0 && active_target == 0 && post_chain 与 present_extra 均为空`。
- 帧间状态：自动填充的链与额外目标在下一帧开头先还原（仅当链仍是自动链时），不污染调用方可见配置。

## 六、注意

- 自动泛光只在「默认路径 + 无用户后处理链」时介入；调用方一旦设置 `post_chain` / `present_extra`，引擎不覆盖。
- 中间目标失败（创建或管线登记）时置 `hdr_bloom_failed`，本帧及后续回落「不泛光」的 HDR 默认路径，不影响出帧。
- 泛光叠加片元对亮度做上限钳制（`clamp(scene + bloom, 0, 1)` 由片元内完成），故末级色调映射前高光已被压到显示域。
