## 二、结果：校验层拒绝，已回退

```
VUID-vkCmdDrawIndexed-dynamicRenderingUnusedAttachments-08910
each element of pColorAttachments must have been created with a VkFormat equal to the corresponding
element of VkPipelineRenderingCreateInfo::pColorAttachmentFormats used to create the bound graphics pipeline
```

原因：同一渲染 pass 内**所有**绘制项都必须使用声明了第二附件的管线。目标通道 / 链呈现里除场景管线外还有
天空盒 / 粒子 / UI / 描边等管线（均为单附件），逐个改造涉及全部管线变体；且在开关关闭的一些组合下仍会命中旧管线。

## 三、结论与方案调整

- MRT（方案 A）的成本比预研估计更高：不是「改 4 处录制路径」，而是「同一 pass 内全部管线都要有双附件变体」。
- 推荐改走**方案 B（独立 id 预通道）**：用一条极简 id 管线（复用实例属性 location 10 的 z = 色调算子）
  把不透明物体画进已有的 `R8` 编号附件，主 pass 保持单附件；末级仍按「id 附件 > alpha > 全局」解码。
  代价：多一次几何提交（仅位置 ＋ 实例属性，无光照 / 纹理），收益是**零管线变体**、零 pass 结构改动。
- 方案 A 保留为「后续可选」；若启用，需一次性为场景 / 天空盒 / 粒子 / UI / 描边准备双附件变体。
