# 中间后处理级保留逐材质色调（第 789 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `ba15bde` / Test `ca3b9a4`（均已推送）

## 一、问题

分级调色 / 描边等单源后处理级此前恒写 `alpha = 1`。把它们放在场景与末级色调之间时，
会冲掉场景 alpha 携带的逐材质色调编号，末级对全部物体回落全局算子。

## 二、实现

- `分级调色.frag`：采样改 `vec4`，输出 alpha 透传 `source.a`；
- `描边.frag`：输出 alpha 透传 `source.a`。

普通场景 alpha 为 1 / 反照率，行为不变；携带编号的像素保留编号。

## 三、验证

新增用例 `Post_Chain.HDR中间级保留逐材质色调`：

- 两级链「分级调色（恒等参数 lift 0 / gamma 1 / gain 1 / sat 1）→ 材质色调映射」，16F 场景 ＋ 16F 中间目标；
- 左材质 AgX、右材质 ACES，纯蓝；
- 断言右半通道差 ≥120、左半低 ≥30（修复前中间级写 1，两侧都回落 ACES，左半不去饱和）。
