# 余下后处理片元透传 alpha（第 792 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `ede1491` / Test `d250802`（均已推送）

## 一、问题

第 790 轮只覆盖「单源取像素」的 13 个调色级。余下 12 个片元仍写 `alpha = 1`：
其中 `伽马校正` / `色彩查找` / `像素化` / `桶形畸变` / `色差` / `锐化` 为单源或邻域采样，
`模糊` / `降采样` / `升采样` / `FXAA` / `景深` / `径向模糊` 为多采样。把它们插在场景与末级色调之间，
同样会把逐材质色调编号冲掉。

## 二、 alpha 语义（本轮定义）

| 类别 | 片元 | 取值 |
| --- | --- | --- |
| 单源 | 伽马校正 / 色彩查找 / 像素化 / 色差 / 锐化 | 中心/块中心源像素的 alpha |
| 重采样（几何） | 桶形畸变 | 双线性采样的 alpha（边缘会混编号，末级按最近编号解码） |
| 多采样（颜色平均） | 模糊 / 景深 / 径向模糊 / FXAA / 降采样 / 升采样 | **alpha 不参与平均**：按中心（块中心 / 最近）像素透传 |

统一步骤：采样改 `vec4`，rgb 走原有算法，alpha 取上述代表像素。
