# 全局后处理参数槽更名（第 795 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `5c3bd8d` / Test 不变 `ea908be`

## 一、问题

自动泛光已在第 778 轮删除，但设备状态里的 `bloom_param[4]` 仍沿用旧名：
实际内容是「链级回落参数（阈值 / 软膝 / 强度）＋ 全局默认色调算子 ＋ 双轨分轨」，与泛光无关，
命名会误导后续维护（也解释了 774 轮为何借泛光接口下发分轨）。

## 二、实现

- 内部字段 `bloom_param` → `global_post_param`（`设备域状态.h`、初始化 / 复位 / 派发 / 设置四处同步）。
- `渲染设备.h` 的 `bloom_param_set` **保留原名与签名**（游戏侧 vendored 副本在用），补充语义注释：
  写入全局回落槽的 x/y/z，逐级专设参数优先；w 与 x/y 另被 HDR 默认路径占用（全局算子 / 分轨）。
