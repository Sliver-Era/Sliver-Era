# 双轨分轨参数改为派发期下发（第 796 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `9c61eae` / Test 不变 `ea908be`

## 一、问题

第 774 轮的实现里，HDR 默认路径在每帧渲染开始调用 `bloom_param_set(split, band, 1.0)`，
把双轨分轨写进**全局回落槽**的 x/y。副作用有两处：
1. 调用方先前通过 `bloom_param_set` 设置的链级回落阈值 / 软膝被静默覆盖（隐藏行为）；
2. 分轨参数只在 `hdr_tone_operator == 5` 时写入，其他算子的帧仍沿用被污染过的槽值。

## 二、实现

- 删除 `渲染器_帧渲染.cpp` 中每帧的 `bloom_param_set` 调用（保留说明注释）。
- `渲染器_帧阶段_分派.cpp` 组装后处理绘制项时：若该级未专设参数，且本帧使用 HDR 默认路径
  （`hdr_targets` 且该级管线就是内置默认末级 `post_pipeline`），则按设备状态下发
  x = 分轨位置、y = 过渡半宽、z = 1、w = 全局算子；其余级仍取全局回落槽。
- 用户自建链（含自建 `材质色调映射` 级）行为不变：未专设时仍取全局回落槽，可继续用
  `post_stage_param4_set` 指定分轨。
