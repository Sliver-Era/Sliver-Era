# 后处理 alpha 守卫脚本（第 798 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：无源码改动（工具脚本新增）

## 一、目的

790–793 轮把 27 个后处理片元的输出 alpha 改为透传源值，但这类回归没有静态守卫：
任何新片元（或后续改动）把 `out_color` 的 alpha 写回常量 1，都会静默破坏逐材质色调编号。

## 二、实现

新增 `检查/后处理alpha守卫.ps1`：

- 扫描 `Engine/EngineRenderer/assets/shaders/*.frag` 的 `out_color = vec4(..., 1.0)`；
- 白名单为「色调映射家族（解码后清编号）」「场景 / 粒子 / 文字 / UI / 天空盒」与 `反向外扩`（几何 pass）、`亮部提取`（泛光链内部）；
- 违规时逐条输出并返回退出码 1，合规输出「0 处」并返回 0；
- 参数 `-Root` 默认 `d:\代码仓库\白银纪元`（与 `源码行数统计.ps1` 同口径）。

## 三、运行结果

```
后处理 alpha 守卫：0 处（无中间级把 alpha 写死为 1）
```

## 四、文件清单（相对工作站根）

## 五、备注

- 脚本需 UTF-8 BOM（Windows PowerShell 5.1 按 ANSI 读取无 BOM 脚本会导致中文乱码）。
- 后续新增后处理片元时，先跑该脚本再提交。
