# 后处理单源调色级透传 alpha（第 790 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `ff64ae2` ＋ `e47d46f` / Test `ca3b9a4`（均已推送）

## 一、问题

第 788 / 789 轮只修了泛光叠加与分级调色 / 描边三处。其余 13 个单源调色级仍输出 `alpha = 1`，
装配到「场景 → 调色 → 材质色调映射」链路时，逐材质色调编号在中间级被冲掉，末级整帧回落
全局算子——与 §0.1 判据①（同帧逐物体各自选色调曲线）冲突。

## 二、实现

| 片元 | 采样改动 | 输出 alpha |
| --- | --- | --- |
| 反色 / 灰度 | 原本即 `vec4` | `source.a` |
| 双色调 / 色彩校正 / 色温 / 色调分离抖动 | `vec3 color` → `vec4 color_texel` ＋ `vec3 color` | `color_texel.a` |
| 对比度 / 饱和度 / 色调分离 / 色相旋转 / 暗角 / 曝光 / 胶片颗粒 | `vec3 source` → `vec4 source_texel` ＋ `vec3 source` | `source_texel.a` |

采样仍为每像素一次（改前取 `.rgb`、改后取整个纹素），无新增纹理取样。普通场景（alpha 为 1
或反照率）画面不变；携带编号的像素把编号带到末级。

头部注释同步为「alpha 透传源值（保留逐材质色调编号）」，并清理改造时产生的重复注释行。

## 五、遗留与下轮

- 多采样级（模糊 / 降采样 / 升采样 / FXAA / 景深 / 径向模糊 / 色差）的 alpha 语义未定义：
  需决定「中心点透传」还是「加权平均」，并补「中间级不丢编号」用例覆盖新改造的代表级。
- 性能：仅着色器 alpha 通道写出变化，无额外取样，判定无性能面。
