# 后处理单源调色级透传 alpha（第 790 轮）· 执行计划

> 日期：2026-11-19
> 起点：Renderer `ba15bde` / Test `ca3b9a4`

## 一、目标

承接第 788 / 789 轮：泛光叠加级与分级调色 / 描边级已透传场景 alpha，但其余单源调色级仍恒写
`alpha = 1`，把它们插在场景与末级色调之间时仍会冲掉逐材质色调编号（场景 alpha 携带的
`(id + 1) × 0.0005`）。本轮把余下「单源取像素 + 只改 rgb」的调色级统一改为透传源 alpha。

## 二、范围（13 个片元）

反色、灰度、双色调、对比度、饱和度、色温、色相旋转、色调分离、色调分离抖动、暗角、曝光、
色彩校正、胶片颗粒。

不含：多采样级（模糊 / 降采样 / 升采样 / FXAA / 景深 / 径向模糊 / 色差）——其 alpha 语义需
单独定义（加权平均 vs 中心点），留待后续方向；色调映射家族输出 alpha 恒 1 属既定口径
（解码后清编号），不在本轮范围。

## 三、实现方式

- 已用 `vec4` 取源的（反色 / 灰度）：输出 alpha 直接取 `source.a`；
- 用 `vec3 X = texelFetch(...).rgb` 的：改为先取 `vec4 X_texel`，再 `vec3 X = X_texel.rgb`，
  输出 alpha 取 `X_texel.a`（保持单次采样，不增加纹理取样次数）；
- 头部注释同步为「alpha 透传源值（保留逐材质色调编号）」。
