# 显式链回落色调算子（第 781 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `c71e55b` / Test `d7ad334`（均已推送）

## 一、问题

779 的逐材质色调只在 HDR 默认路径生效（引擎内置末级片元）。调用方自行装配后处理链时，
若使用 `材质色调映射.frag`，其全局回落算子只能手工写 `post_stage_param4_set(…, w)`，语义不明确且容易漏设。

## 二、实现

新增 `Render_Device::post_stage_tone_operator_set(uint32_t stage, uint32_t tone_operator)`：

- 级序须落在当前链内（链外告警忽略）；
- 写该级推送块 offset 96 的第四分量，并标记该级参数有效；
- 合法域 0..5（0 ACES / 1 胶片 / 2 指数 / 3 扩展 Reinhard / 4 AgX / 5 双轨），越界按 0；
- 只影响未覆盖像素：逐材质覆盖仍按场景 alpha 优先。

## 三、验证

新增用例 `Renderer_Post_Chain_Test.HDR显式链逐材质色调`：

- 自建 16F 场景目标 ＋ 16F 场景管线 ＋ `材质色调映射.frag` 单级链，回落算子设 ACES；
- 左材质 AgX（4）、右材质 ACES（0），纯蓝纹理；
- 断言：右半通道差 ≥120（ACES 保纯色）、左半低至少 30（AgX 去饱和）；`post_stages = 1`。
