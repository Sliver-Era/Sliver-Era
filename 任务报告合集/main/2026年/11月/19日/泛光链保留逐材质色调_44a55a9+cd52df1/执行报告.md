# 泛光链保留逐材质色调（第 788 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `44a55a9` / Test `cd52df1`（均已推送）

## 一、问题

逐材质色调编号借场景目标 alpha 传递。泛光链的叠加级此前恒写 `alpha = 1`，
使编号在「场景 → 提取 → 模糊 → 叠加」路径上被冲掉，末级只能对所有物体回落全局算子 ——
「逐材质色调 ＋ 泛光」组合实际退化为全局算子（与 762 的全帧妥协等价）。

## 二、实现

`泛光叠加.frag`：采样场景改为 `vec4`，输出 alpha 改为透传 `scene.a`（第 788 轮）。
普通场景 alpha 为反照率 / 1，行为与之前一致；只有携带编号的像素保留编号。

## 三、验证

新增用例 `Post_Chain.HDR泛光链保留逐材质色调`：

- 显式四级链（提取 → 模糊 → 叠加 → 通用色调末级），16F 场景目标；
- 左材质 AgX、右材质 ACES，纯蓝纹理；
- 断言：右半通道差 ≥120（ACES 保纯色）、左半低 ≥30（AgX 去饱和）；
- 修复前两侧都会走全局 ACES，左半不会去饱和。

| 非渲染层 | 本轮无改动，沿用 **783 / 783** |
