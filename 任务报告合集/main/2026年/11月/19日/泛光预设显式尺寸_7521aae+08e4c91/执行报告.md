# 泛光预设显式尺寸（第 783 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `7521aae` / Test `08e4c91`（均已推送）

## 一、问题

778 的显式泛光预设固定取当前客户区尺寸建中间目标。调用方在离屏目标、SSAA 或自定义分辨率下装配泛光时无法使用。

## 二、实现

`post_bloom_preset_build(preset, desc, width = 0, height = 0)`：

- `width / height` 为 0 时取当前客户区尺寸（与 778 行为一致，默认调用不受影响）；
- 非 0 时按该尺寸建立三个 16F 中间目标（半分辨率描述下提取 / 模糊取 1/2 边长、叠加保持全尺寸）；
- 参数有限性加固：`desc.radius` 非有限时回落 4.0（此前 NaN 会静默丢弃该级参数）。

## 三、验证

新增用例 `Post_Chain.HDR泛光预设显式尺寸`：

| 场景 | 目标尺寸 |
| --- | --- |
| 显式 32×18（全分辨率） | 三个目标均 32×18 |
| 显式 32×18（half_res） | 提取 / 模糊 16×9，叠加 32×18 |
| 不传尺寸 | 三个目标均等于当前客户区 |

| 项目 | 结果 |
| --- | --- |
| `Post_Chain.HDR*` | **25 / 25**（Debug） |
| 非渲染层 | 本轮无改动，沿用 **783 / 783** |
