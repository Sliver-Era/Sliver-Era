# 公开逐材质 PBR 特性位常量（第 786 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `192d1f8` / Test `00540f0`（均已推送）

## 一、目的

777 的逐材质特性以裸位号（`1u << 2` 等）出现在调用方与用例中，可读性差且易写错位。本轮把位定义提升为公共常量。

## 二、实现

`材质数据.h` 新增（公共、Vulkan-free）：

| 常量 | 值 |
| --- | --- |
| `PBR_FEATURE_MULTISCATTER` | 1 << 0 |
| `PBR_FEATURE_FRESNEL_ROUGHNESS` | 1 << 1 |
| `PBR_FEATURE_ANISO` | 1 << 2 |
| `PBR_FEATURE_SKIN_SSS` | 1 << 3 |
| `PBR_FEATURE_SHEEN` | 1 << 4 |
| `PBR_FEATURE_GLOSS_MAPPING` | 1 << 5 |
| `PBR_FEATURE_ALL` | 0x3F |

`material_load` 的掩码裁剪改用 `PBR_FEATURE_ALL`；测试用例全部改用常量（各向异性 / sheen / SSS / 光泽度映射 / 性能基线）。
