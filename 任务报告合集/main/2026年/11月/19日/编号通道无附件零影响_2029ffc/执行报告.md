1. 同一场景（纯绿纹理 ＋ 全屏四边形）对「普通 8 位目标（无编号附件）」渲染两帧——
   一帧 `tone_id_pass_set(false)`、一帧 `true`，回读目标颜色逐字节比较；

## 三、段 4 设计（写入预研 §九，下一轮实施）

1. **绑定**：采样集新增 `binding 10`（`COMBINED_IMAGE_SAMPLER`，片元阶段）；
   默认写入 1×1 `R8_UINT` 零图（值 0 = 无覆盖），既有阶段不读取该绑定 → 画面不变。
2. **门面**：`post_tone_id_target_set(uint64_t render_target_handle)` —— 记录目标编号视图；
   帧组装后处理绘制项时把该视图写进 sampling 集 binding 10（未设置 → 默认零图）。
3. **着色器**：`材质色调映射.frag` 增 `layout(set=1, binding=10) uniform usampler2D tone_id_tex;`
   `uint id = texelFetch(tone_id_tex, ivec2(gl_FragCoord.xy), 0).r;`
   `id` 在 1..5 时按 `id - 1` 选曲线，否则回落 alpha 解码 → 全局；UINT 采样避免 sRGB / 归一化歧义。
4. **验收**：同场景开 / 关通道的末级输出——无编号附件时逐字节一致；有编号附件时逐材质算子与 16F 路径一致；
   中间级链不读该绑定。
5. **风险点**：所有既有的采样集写出点（场景 / 后处理 / UI / 逐项）都必须补 binding 10，漏写会触发校验层；
   建议先用默认零图统一填充，再按需覆盖。
