# 渲染目标可选色调编号附件（第 801 轮 · 8 位 MRT 段 1）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `3405abd` / Test `d59a5e6`（均已推送）

## 一、目标

按 `深研预研_8位路径逐材质色调.md` 方案 A 落地**段 1（资源层）**：渲染目标可选携带一个单采样
颜色附件（建议 `R8_UINT`），专写逐像素色调编号；默认不启用，既有路径逐字节不变。

## 二、实现

- `Render_Target_Record`：新增 `tone_id_image / tone_id_alloc / tone_id_view / tone_id_format`。
- `target_create(..., sample_count, tone_id_format = UNDEFINED)`：非未定义且采样数 1 时创建
  `COLOR_ATTACHMENT | SAMPLED` 图像与视图；采样数 > 1 时告警并跳过（MSAA 解析留后续段）。
- 初始布局转换：新增第二条屏障（未定义 → 着色器可读）。
- 销毁：`record_resources_destroy` 归还；门面 `render_target_destroy` 的延迟队列追加一条内存资源
  （**首跑即暴露 VMA「Unfreed dedicated allocations」断言，补该条后通过**）。
- 查询：`target_tone_id_get` / 门面 `render_target_tone_id_get`。
- 门面：新增 `render_target_create_format_ex(..., tone_id_format, sample_count = 0)`；
  原 `render_target_create_format` 行为不变。

## 三、验证

| 项目 | 结果 |
| --- | --- |
| Renderer Debug / Release | 零错误 |
| `Renderer_Offscreen_Test.*` | **12 / 12**（Debug，19.7 s；含新用例） |

新用例 `色调编号附件资源层`：单采样创建→查询命中（格式 `R8_UINT`）→销毁后查询失败；
多重采样目标不创建编号附件但仍创建成功；不指定格式与既有接口一致。
