# 收窄逐材质色调编号的 alpha 编码（第 784 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `9534519` / Test `08e4c91`（未改）

## 一、问题

779 起的逐材质色调编号借用场景目标 alpha 传递，编码为 `(id+1)/255`（0.0039..0.0196），解码阈值为 `<0.05`。
粒子等透明绘制也会写 alpha（软边 / 寿命淡出 / 软粒子深度淡出），其 alpha 落入该区间时会被误判为「材质覆盖」，
从而对**非材质对象**应用了错误的色调曲线。

## 二、实现

- 场景片元：覆盖编码改为 `(id+1) × 0.0005`（0.0005..0.0025）；
- 末级片元：解码阈值收窄为 `< 0.003`，`floor(a × 2000 + 0.5) − 1`；
- 16F 精度校验：0.0025 在 half 下的相对误差约 0.1%，×2000 后仍稳定取整。

收窄后，碰撞只可能发生在 alpha ≤ 0.3% 的像素上——这类像素在画面上几乎不可见，误判的视觉影响可忽略。
