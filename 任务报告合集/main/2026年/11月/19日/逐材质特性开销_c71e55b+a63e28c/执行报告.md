# 逐材质 PBR 特性开销基线（第 782 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `c71e55b`（未改）/ Test `a63e28c`（已推送）

## 一、目的

777 把 PBR 特性从全局开关改为材质位掩码，并在实例数据上增加了 16 字节（112 → 128）。需要一组可复现数据，
证明「逐材质」路径没有引入数量级开销，作为后续特性扩展的性能守卫。

## 二、实现

新增用例 `Renderer_Scene_Test.PBR逐材质特性开销`：

- 640×360、1000 实例、全局特性全关；
- 材质 A：不覆盖（`pbr_features_override = false`）；
- 材质 B：掩码 bit0..4 全开（多散射 / Fresnel-roughness / 各向异性 / 皮肤 SSS / sheen）；
- 中位帧耗时（3 帧预热 ＋ 20 帧采样，vsync / 校验层关闭）；
- 断言：覆盖版不得超过基线的 2 倍 ＋ 0.5 ms（宽上限，仅防数量级劣化）。

## 三、实测

| 配置 | Debug（ms） | Release（ms） |
| --- | --- | --- |
| 材质不覆盖（基线） | 0.2351 | 0.2117 |
| 材质掩码全开（5 项） | 0.2774 | 0.2436 |
| 增量 | +0.0423（+18%） | +0.0319（+15%） |

结论：Release 增量约 **0.03 ms / 1000 实例**，与整改前全局特性的 0.224–0.294 ms 区间同量级；
实例步长增加 16 字节未在 CPU 侧表现为显著开销。数据已归档 `性能基线_方向九.md`。
