# 通用引擎化整改（777–779）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `6e3860b` / Test `e7963a1`（均已推送）
> 回归：Debug 渲染层 **834 / 834**、非渲染层 **783 / 783**；Release 关键子集 **54 / 54**

## 一、目标与背景

用户判定：方向八（前向 32 槽 / 聚光阴影 / 接触阴影）与 HDR 通路（16F 目标 ＋ 末端色调映射）**该在核心**；
但方向九的 PBR 全局开关、隐式自动泛光、全局唯一色调算子把「演示特性」硬塞进核心并固化了全局美术风格。

三条硬判据（已写入 `自主迭代规则.md` §0.1）：① 同帧不同物体可各选材质特性与色调曲线；② 后处理链由调用方显式组装；③ 关闭可选能力时逐字节不变。

## 二、777 · PBR 特性材质化

### 新增字段

| 位置 | 字段 |
| --- | --- |
| `Material_Data` / `Material_Record` | `bool pbr_features_override`、`uint32_t pbr_features`（bit0 多散射 / bit1 Fresnel-roughness / bit2 各向异性 / bit3 皮肤 SSS / bit4 sheen / bit5 光泽度映射）、`float pbr_gloss`（-1 = 不启用） |
| `Resource_State` | `material_pbr_features_active`、`material_pbr_features` |
| `Instance_Material_Values` | `pbr_features_active`、`pbr_features` |

### 数据通路

- 实例步长 **112 → 128 字节**（`INSTANCE_FLOAT_COUNT 28 → 32`），新增第 5 个 vec4（偏移 28）：
  x = 覆盖标志、y = 位掩码、z = 逐材质色调算子（779 使用）、w 保留。
- 图形管线：实例属性 location 10（`R32G32B32A32_SFLOAT @112`），属性集合扩为 11 条。
- `场景.frag` 新增 `pbr_feature_on(bit, 全局值)`：材质覆盖时按位查询，否则回落场景 UBO 全局开关。
  替换 5 处门控；**镜面 AA（`lighting_extra.w`）保持全局**（管线级口径）。
- 光泽度映射：bit5 且 `pbr_gloss ∈ [0,1]` 时按 `roughness = clamp(1 − gloss, 0.05, 1)` 覆盖本材质粗糙度，
  并强制登记为逐物体 PBR 覆盖。此前该开关只写 UBO `out[987]`、**无任何片元读取（死开关）**，本轮一并修掉。

### 缺陷修复

`图形管线.cpp` 的 `VkVertexInputAttributeDescription vertex_attributes[10]` 容量不足：场景着色器声明 location 0..10 共 11 条属性时越界，
Debug 直接触发 **Run-Time Check Failure #2（Stack around the variable 'vertex_attributes' was corrupted）**；容量改 11。

## 三、778 · 自动泛光改为显式预设

### 删除

- `Renderer_Config::hdr_auto_bloom / hdr_bloom_threshold / hdr_bloom_knee / hdr_bloom_radius / hdr_bloom_intensity / hdr_bloom_half_res`；
- `Device_State` 的泛光目标 / 管线 / 尺寸 / 失败标志 / 链填充标志；
- `Device_State::hdr_bloom_ensure / hdr_bloom_destroy / hdr_bloom_frame_apply` 与帧内隐式调用。

### 新增

| 接口 | 语义 |
| --- | --- |
| `bool post_bloom_preset_build(Bloom_Preset&, const Bloom_Preset_Desc&)` | 建 3 个 16F 中间目标（半分辨率时提取 / 模糊取 1/2 边长）＋ 3 条 16F 管线（亮部提取 / 模糊 / 泛光叠加）；重复调用先释放旧资源 |
| `bool post_bloom_preset_params(const Bloom_Preset&, const Bloom_Preset_Desc&)` | 校验链前三级确为本预设后，下发阈值 / 软膝 / 半径 / 强度（半径钳 1..4，半分辨率按纹素折算） |
| `void post_bloom_preset_release(Bloom_Preset&)` | 归还中间目标与管线（管线卸载会摘除链引用） |

装配顺序（调用方掌握）：
`post_chain_set([提取,模糊,叠加,末级],4)` → `render_target_present_chain_set([场景,目标0,目标1,目标2],4)` → `post_bloom_preset_params`。

**踩坑记录**：`render_target_present_set` 会把目标组重置为「仅该目标」（清空 `present_extra`），
链装配后再调用会退化为单级；本版次测试迁移首跑即因此得到 `post_stages = 1`。

### 测试迁移

原 5 个自动泛光用例（默认 / 参数化 / 随尺寸重建 / 半分辨率 / 组合矩阵 / 算子矩阵）改为显式装配；
新增「未装配时链恒为空、单级」与「引擎不隐式介入用户链」两个守卫。

## 四、779 · 逐材质色调算子

| 项 | 内容 |
| --- | --- |
| 材质字段 | `Material_Data::tone_operator`（0 ACES / 1 胶片 / 2 指数 / 3 扩展 Reinhard / 4 AgX；0xFF 继承全局） |
| 数据通路 | 实例第 5 向量 z → `场景.frag` 输出 alpha = `(id+1)/255`（未覆盖时沿用反照率 alpha） |
| 末级 | 新增 `材质色调映射.frag`：源 alpha < 0.05 视为覆盖，`floor(a*255+0.5)−1` 最近邻取编号；否则用推送常量 offset 96 的 w 作为全局默认；算子 5（双轨）保留区域过渡 |
| 管线选择 | `post_pipeline_ensure` 在 `hdr_targets` 时统一改用该片元（原「按全局算子选五个片元」删除） |

效果：同一帧内写实物体可走 AgX、二次元物体可走 ACES，762 的「AgX 压灰纯色（141 vs 247）」不再需要全帧妥协。

已知边界（已写入着色器与导航）：编号依赖 16F 场景目标 alpha，且会改写 alpha，故只适合不透明材质；MSAA 解析在边缘会平均 alpha，边缘像素回落默认算子。
