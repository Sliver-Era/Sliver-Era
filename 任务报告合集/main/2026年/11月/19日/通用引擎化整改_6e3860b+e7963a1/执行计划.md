# 通用引擎化整改（777–779）· 执行计划

> 日期：2026-11-19
> 依据：用户当日指示——渲染核心是「通用渲染引擎」，场景只是能力覆盖范围；PBR 特性应属材质、泛光应显式装配、色调算子应逐材质。
> 计划文档：工作站 `深研计划合集/深研规划/整改计划_通用引擎化.md`

## 一、目标

把三项「全局固化」改为「逐物体 / 可组装」：

1. 六项 PBR 特性（多散射 / Fresnel-roughness / 各向异性 / 皮肤 SSS / sheen / 光泽度映射）从 `Renderer` 全局开关迁到 `Material_Data`；
2. 删除 `hdr_auto_bloom` 与引擎隐式建资源，提供显式泛光预设 API；
3. 色调算子从「全帧唯一」改为「逐材质编号」，全局算子降级为默认值。

## 三、执行分段

1. **阶段一（777）**：实例布局扩位 → 材质字段 → 片元门控 → 构建双配置 → 修属性数组越界 → 新用例 → 渲染层全量。
2. **阶段二（778）**：删除隐式泛光 → 预设 API → 测试迁移 → HDR 子集与全量。
3. **阶段三（779）**：材质色调字段 → alpha 编号 → 通用末级片元 → 同帧用例 → 全量 ＋ Release 子集。

## 四、验收口径

- 三条硬判据：同帧不同物体可各选特性与曲线；后处理链由调用方显式组装；关闭能力时逐字节不变。
- 每阶段：Debug 全量 ＋ Release 受影响套件；两仓提交推送；报告 / 汇总 / 导航同步。
