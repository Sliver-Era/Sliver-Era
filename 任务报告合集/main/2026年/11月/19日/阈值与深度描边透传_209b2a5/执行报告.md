# 亮度阈值与深度描边透传 alpha（第 793 轮）· 执行报告

> 日期：2026-11-19
> 代码版次：Renderer `209b2a5` / Test 不变 `d250802`（均已推送）

## 一、问题

`亮度阈值.frag` 与 `深度描边.frag` 是后处理链中的常见中间级，仍输出 `alpha = 1`：
- 亮度阈值常用于「二值化 / 遮罩」风格化链，放在场景与末级色调之间会把逐材质色调编号压成 1；
- 深度描边用于二次元描边，同样会冲掉编号。

## 二、实现

- `亮度阈值.frag`：采样改 `vec4`，输出 alpha 取源纹素 alpha（rgb 仍按 0.5 阈值二值化）。
- `深度描边.frag`：末尾输出 alpha 由 1 改为 `source.a`（源纹素原本已是 `vec4`）。

## 三、复核结论（不改动）

| 片元 | 结论 |
| --- | --- |
| `接触阴影.frag` | 已输出 `color.a`，无需改动 |
| `体积光.frag` / `体积雾.frag` / `屏幕空间遮蔽.frag` / `屏幕空间反射.frag` | 已输出采样得到的 `color.a` |
| `反向外扩.frag` | 几何外扩描边 pass（无源纹理），不属于后处理链 |
| `亮部提取.frag` | 泛光链内部中间级，alpha 由 `泛光叠加` 统一取场景 alpha |
| 色调映射家族（含 `材质色调映射`） | 恒写 1 属既定口径（解码后清编号） |
