# 执行计划（UI 域内事件总线 · 方式一局域网）

- 任务：把渲染核心 UI 系统改为「以事件终端为中心」的域内局域网，自建 `UI/*` 协议，对外经网关翻译为 EngineSystem 的 `Input/*` 协议。

- 工作站：`D:\agent\working_station\silver_era`
- 改动范围：`Engine/EngineRenderer/src/render/UI/` 与 `Application/Test/tests/Renderer/`
- 不改动：EngineSystem、EngineFoundation、Frame 的 UI pass、渲染层其它域

## 一、目标与边界

1. UI 域内以一台中心 `Event_Terminal` 为局部路由，内部节点（控件树 / 交互 / UI 渲染器 / 事件桥）通过端口绑定接入，不再互相持有函数指针。
2. 自建 `UI/*` 协议（`category = "UI"`），域内事件**不登记到 Broker**，外部结构上订阅不到。
3. 网关负责双向翻译：内部 `UI/*` → 外部 `Input/*`；外部 `Input/*` → 内部 `UI/*`。
4. 焦点以系统焦点系统为权威：`Input/FocusChanged` 覆盖 UI 内部投影，UI 内不回传焦点。
5. 控件级兼容：保留 `on_click / on_toggle / on_value` 回调入口，内部转成 `UI/*` 事件，回调等价于「只订阅自己」。

## 二、协议设计（`UI/common/UI事件协议.h`）

- `category = "UI"`
- 出站（域内）：
  - `Click`：`handle`
  - `Toggle`：`handle`、`checked`
  - `Value`：`handle`、`value`
  - `Hover`：`handle`、`inside`
  - `Submit`：`handle`、`text`
  - `TextInput`：`text`、`cursor`
  - `ModalOpened` / `ModalClosed`：`handle`
  - `FocusChanged`：`handle`、`main`、`child`、`modal`、`text`
  - `Activate`：`command`、`handle`
- 入站（由网关翻译后注入）：`Activate`、`TextInput`、`FocusChanged`、`TextMode`
- 字段名统一以 `field_` 前缀常量导出。

## 三、翻译粒度（定案）

| 内部事件 | 对外处理 |
| --- | --- |
| `UI/Click` | 不出域；有命令绑定 → 立即 `Input/Command`；有回调 → 本地同步调用 |
| `UI/Toggle` | 不出域；有命令绑定 → 立即 `Input/Command`（带 `checked`） |
| `UI/Value` | 不出域；有命令绑定 → 帧末合并 `Input/Command` |
| `UI/Hover` | 帧末合并；悬停控件变化时才发 `Input/MouseFocus` |
| `UI/Submit` | 立即 `Input/TextSession` |
| `UI/ModalOpened` / `Closed` | 立即 `Input/ModalPush` / `ModalPop` |
| `UI/FocusChanged` | 仅内部投影，不回传 |

入站：`Input/Command → UI/Activate`、`Input/Text → UI/TextInput`、`Input/FocusChanged → UI/FocusChanged`、`Input/TextMode → UI/TextMode`。

防环：网关翻译产出的事件在 `config` 标记 `origin = "gateway"`；带该标记的事件不再回译。
