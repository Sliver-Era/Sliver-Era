# 执行报告：转移与镜像的配置复制

## 一、任务结论

转移与镜像不再只搬几何：

- `collider_transfer`：几何、检测方式、豁免标记、运动量与作用频率全部随原编号进入目标空间；运动步长不满足时拒绝转移。
- `collider_mirror`：复制几何、检测方式与豁免标记，返回新编号；不复制运动，新编号从静止开始。
- 两者失败时回滚占位碰撞体，不再残留半成品。

构建与测试：EngineSystem / TestSystem 的 Debug 与 Release 均构建通过；碰撞套件双配置 **66 / 66 通过**。

## 四、关键实现细节

### 4.1 转移

```text
读取源几何 + 检测方式 + 豁免标记
→ 目标 collider_adopt(原编号)
→ 源 collider_unload(原编号)
→ 目标 collider_set(geometry)
→ 目标 collider_set(detection_mode) / collider_set(exemption_flag)
→ 更新编号归属
→ 代理器重新下发运动量与频率
```

失败路径：几何重建失败时先 `target->collider_unload`，再在源空间 `collider_adopt` 并回填几何与配置，最后返回失败；编号归属只在全部成功后更新。

### 4.2 镜像

```text
读取源几何 + 检测方式 + 豁免标记
→ 目标 collider_build(新编号)
→ 目标 collider_set(geometry, collider_ID = 新编号)
→ 目标 collider_set(detection_mode) / collider_set(exemption_flag)
→ 出参返回新编号
```

几何重建失败时调用 `collider_unload(新编号, 目标空间)` 回滚。
镜像不写 `motion_records`，因此新编号没有运动；需要运动时由调用方发送新的 `ColliderMotion`。

### 4.3 编号与归属

- 转移保留原编号，`motion_records` 中的登记按编号继续有效，转移后由代理器重新下发。
- 镜像使用目标空间分配器的新编号，不触碰源编号的运动登记。
- 同数字编号跨空间共享运动登记的旧口径未改动。

## 六、已知限制

1. 镜像不复制运动是刻意语义：新编号代表新身份，运动应由调用方显式下发。
2. 运动登记仍以数字编号为键，跨空间同编号碰撞体共享登记（旧口径）。
3. 顶层版本锁提交未推送：顶层工作区落后远端 596 个提交，合并需用户确认后再处理。
