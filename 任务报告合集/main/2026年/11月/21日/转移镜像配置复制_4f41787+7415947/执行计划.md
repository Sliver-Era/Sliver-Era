# 执行计划：转移与镜像的配置复制

## 一、任务背景

现行 `collider_transfer` 只把几何配置搬到目标空间，`collider_mirror` 只复制几何且不返回新编号；
检测方式、豁免标记在目标空间回到默认值，镜像的新编号也无法被调用方取得。

## 二、目标行为

1. 转移：几何、检测方式、豁免标记、运动量与作用频率全部随碰撞体进入目标空间。
2. 镜像：复制几何、检测方式、豁免标记；不复制运动（新编号从静止开始）；新编号可被调用方取得。
3. 转移/镜像失败时回滚已创建的占位碰撞体，不留下半成品。
4. 转移前复核运动登记与离散步长：含旋转或部件运动而步长为零时拒绝转移。

## 四、验收口径

- 转移后扫掠/离散步长、豁免组、运动与频率保持原值；同豁免组不产生碰撞对。
- 镜像返回新编号；几何、检测方式、豁免标记与源一致；镜像不继承源运动。
- 转移/镜像失败不残留占位碰撞体。
- 碰撞套件 Debug / Release 全部通过。

## 五、验证方式

- 构建：EngineSystem Debug/Release、TestSystem Debug/Release。
- 测试（工作目录 `Application\Test`）：`TestSystem.exe --gtest_filter=*Collision*:*Collider*`。
