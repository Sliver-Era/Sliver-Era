# 执行计划：运动登记改为载荷事件驱动

## 一、任务背景

现行碰撞运动通道把 `ColliderMotion` 的原始 JSON 长期保存在代理器内，并在每次检测（或每个生效帧）重新解析，
既保留了「事件即共享状态」的旧机制，也带来每帧 JSON 解析与校验开销。

## 二、目标行为

1. 运动状态只由新的 `ColliderMotion` 载荷事件更新；事件到达时一次性解析并下发到碰撞空间。
2. 未收到新事件时，碰撞空间直接沿用上次下发的运动量持续施加，不再回读、不再解析事件。
3. 删除代理器到碰撞空间的运动读取回调链路（`motion_reader` / `motion_reader_set` / `motion_reader_bind` / `motion_seek`）。
4. 保持既有语义：作用频率拆分、含旋转或部件运动须显式步长、几何重建按子部件编号裁剪、步长归零清除旋转/部件登记。

## 三、文件清单（相对项目根）

### 3.1 碰撞代理器

- `Engine/EngineSystem/src/collision/Collision_Proxy/碰撞代理器.h`
  - `motion_events`（原始 JSON）改为 `motion_records`（已解析 `Motion_Event` ＋ 频率）。
  - 删除 `motion_seek`；新增 `motion_apply` / `motion_frequency_apply` / `motion_clear`。
- `Engine/EngineSystem/src/collision/Collision_Proxy/core/运动管理.cpp`
  - 登记时解析并保存解析值，随后一次性下发运动量与频率。
  - 删除查询与重解析逻辑。
- `Engine/EngineSystem/src/collision/Collision_Proxy/core/碰撞体管理.cpp`
  - 卸载：无空间持有该编号时丢弃运动登记，避免编号回收后继承旧运动。
  - 转移：成功后把运动量与频率重新下发到目标空间。
- `Engine/EngineSystem/src/collision/Collision_Proxy/core/空间管理.cpp`
  - 构造时不再绑定读取回调。
  - 空间卸载后清理已无归属的运动登记。
- `Engine/EngineSystem/src/collision/Collision_Proxy/core/碰撞体配置.cpp`
  - 几何重建后按子部件存在性裁剪运动登记并重新下发。
  - 步长归零时清除含旋转或部件运动的登记并同步清空空间内运动。
- `Engine/EngineSystem/src/collision/Collision_Proxy/backend/代理后端.h`
- `Engine/EngineSystem/src/collision/Collision_Proxy/backend/core/空间编排.cpp`
  - 删除运动读取回调成员、绑定方法及新建空间时的注入。

### 3.2 碰撞空间

- `Engine/EngineSystem/src/collision/Collision_Region/碰撞空间.h`
  - 删除 `motion_reader` 与 `motion_reader_set`。
  - 新增 `collider_motion_set`。
- `Engine/EngineSystem/src/collision/Collision_Region/core/碰撞体管理.cpp`
  - 实现 `collider_motion_set`（写入整体/部件总量并清零本帧施加量）。
- `Engine/EngineSystem/src/collision/Collision_Region/core/检测执行.cpp`
  - 删除事件重读分支；未配置频率时直接施加已存运动，配置频率时仅在生效帧拆分。

### 3.3 测试

- `Application/Test/tests/System/src/碰撞/碰撞代理测试.cpp`
  - 新增：新载荷事件覆盖旧登记、编号复用不继承旧运动。
  - 既有持续生效、几何重建裁剪、步长清零用例保持通过。

## 四、验收口径

- 未发送新事件时，连续检测持续施加同一运动量。
- 发送新事件后，只施加新运动量，旧值不再生效。
- 卸载碰撞体后同编号新碰撞体不产生任何旧运动。
- 碰撞相关用例全部通过；EngineSystem Debug 构建零错误。

## 五、验证方式

- 构建：`EngineSystem` / `TestSystem` 的 `x64-Debug` 预设。
- 测试：以 `Application\Test` 为工作目录运行
  `TestSystem.exe --gtest_filter=*Collision*:*Collider*`。
