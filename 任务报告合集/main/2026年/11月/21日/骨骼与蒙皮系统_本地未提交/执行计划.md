# 执行计划 —— 骨骼与蒙皮系统（EngineSystem 一期）

## 一、任务定位

在 EngineSystem 新增骨骼与蒙皮模块，一期范围限定为「CPU 侧语义与求值」：

- 骨骼资产：层级、绑定姿态、逆绑定矩阵、骨骼名索引、骨骼与碰撞子部件的映射模板；
- 演员姿态：每演员姿态组件，层级求值出骨骼世界矩阵（演员根局部空间）；
- 蒙皮求值：`蒙皮矩阵 = 骨骼世界矩阵 × 逆绑定矩阵`，输出关节调色板（中立浮点数据）；
- 碰撞驱动数据：按 `Skeleton_Link` 计算部件相对上一帧的平移/旋转增量，输出中立 `Skeleton_Part_Motion`，由调用方转投碰撞系统。

不在本期范围：动画剪辑采样、glTF 蒙皮导入、GPU 蒙皮管线（渲染层）、碰撞事件发布（由调用方转发）。

## 三、数据契约

- 坐标空间：骨骼姿态与蒙皮矩阵均在「演员根局部空间」；根变换由调用方通过碰撞整体运动或渲染实例矩阵承担。
- 矩阵布局：`float[16]` 列主序，与 glTF / 渲染层一致。
- 姿态组件 `Skeleton_Pose`：持有共享资产指针、逐骨骼局部 TRS、世界矩阵、蒙皮矩阵、脏标记。
- 链接组件 `Skeleton_Link`：碰撞体编号、逐部件绑定（骨骼下标 + `part_ID` + 相对 TRS）、上一帧部件矩阵、本帧部件运动量。
- 资产编号从 1 起，0 表示无效；资产槽位不回收复用。

## 四、执行分段

1. 数学与资产：矩阵构建/乘法/仿射求逆/分解、JSON 资产解析与校验、逆绑定矩阵缺省推导。
2. 组件：`Skeleton_Pose` 初始化/复位/局部写入/世界矩阵读取；`Skeleton_Link` 绑定构建与首帧基准矩阵。
3. 系统：资产登记、演员挂载/卸载、帧求值（姿态 → 蒙皮 → 部件运动）、查询接口。
4. 构建：EngineSystem Debug / Release 双配置构建并修复编译问题。
5. 测试：新增五组用例（资产、姿态、蒙皮、链接、系统集成），使用可执行文件目录绝对路径写临时 JSON。
6. 验证：构建并运行 TestSystem 新增套件与 ECS 受影响套件；不做全量回归。

## 五、验收口径

- 单根 + 子骨骼的层级求值结果与手工矩阵一致；
- 逆绑定矩阵缺省时能由绑定姿态推导，蒙皮矩阵在绑定姿态下为单位矩阵；
- 姿态变更后部件运动量为相对上一帧的增量，首帧不产生跳变；
- 非法资产（缺字段、父下标越界、重名、零四元数、重复 `part_ID`）被拒绝且输出清空；
- ECS 组件增删、实体销毁后的级联清理正常。
