## 约定

1. 各主体的分册、报告分册、索引与里程碑独立维护，轮次从 1 起各自计数。
2. 分册每 25 轮一份，索引每份上限 500 轮，正文逐字保留。
3. 深研文档仍存放于工作站根部的 `深研计划合集/`，与逐轮迭代文档分开。
