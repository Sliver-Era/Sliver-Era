## 第 121 轮 · 级联阴影两级最小实现

- 提交：Renderer `f0cac9b → 63059d8`；Test `13ad872 → 9fca54c`（均已推送）。
- **接口**：`shadow_cascade_set(count, far_scale, split_distance)` / `shadow_cascade_get`；级联数仅 1 / 2，默认 `1 / 3 / 12`，非法整次忽略。
- **几何**：双级为「以相机为中心的两片包围球」（半径 `split` 与 `split × far_scale`），光源机位退到「半径 ＋ 近平面」，深度跨度 `2R + 2 × near`；片元按与相机的距离选级。

- **单级不变**：默认 1 级时矩阵、深度跨度（59）与着色器路径均回到旧口径，画面逐字节一致。
- 验证：新增 4 例级联用例；场景套件 **68 / 68 通过**；全量回归（排除四叉树两套件）**820 通过**，12 例 EngineCore 失败属用户并行在途；校验 0 消息；Debug / Release 0 error。
