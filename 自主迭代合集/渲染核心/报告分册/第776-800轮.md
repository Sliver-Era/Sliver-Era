## 第 777 轮 · 通用引擎化整改 ①：PBR 特性改为材质字段

- 背景（用户 2026-11-19 指示）：渲染核心应是**通用渲染引擎**；七个 PBR 特性里只有镜面 AA 属管线口径，其余六个应属材质。
- `Material_Data` / `Material_Record` 新增 `pbr_features_override`、`pbr_features`（bit0 多散射 / bit1 Fresnel-roughness / bit2 各向异性 / bit3 皮肤 SSS / bit4 sheen / bit5 光泽度映射）、`pbr_gloss`；`material_bind_set` 同步到资源域状态。
- 实例数据 `INSTANCE_FLOAT_COUNT 28 → 32`（步长 **112 → 128 字节**），新增 location 10 的 vec4：x = 覆盖标志、y = 位掩码、z = 逐材质色调算子（779 使用）、w 保留。
- `场景.frag` 新增 `pbr_feature_on(bit, 全局值)`：材质未覆盖时回落场景 UBO 全局开关；替换 5 处门控，镜面 AA 保持全局。
- 缺陷修复：`图形管线.cpp` 属性数组原容量 10，新增第 11 条（location 10）时越界，Debug 触发 Run-Time Check Failure #2；容量改 11。
- 顺带修复：`pbr_gloss_mapping` 此前只写 UBO `out[987]`、无片元读取（死开关）；现按 bit5 + `pbr_gloss` 覆盖本材质粗糙度。
- 新增用例 `Scene.PBR特性逐物体分层`：同帧「普通 / sheen / 光泽度映射」三层互不影响；空掩码与普通材质逐字节一致。契约常量 `INSTANCE_STRIDE_BYTES` 112 → 128。
- 验证：Debug 渲染层 **834 / 834**、非渲染层 **783 / 783**；Release 关键子集 **54 / 54**。Renderer `6e3860b` / Test `e7963a1`（三阶段同批提交）。

## 第 779 轮 · 通用引擎化整改 ③：逐材质色调算子

- `Material_Data` / `Material_Record` 新增 `tone_operator`（0 ACES / 1 胶片 / 2 指数 / 3 扩展 Reinhard / 4 AgX；0xFF = 继承全局），实例第 5 向量 z 承载。
- `场景.frag`：材质请求覆盖时把 `(id+1)/255` 写进输出 alpha；未请求时沿用反照率 alpha（默认画面逐字节不变）。
- 新增 `材质色调映射.frag`：按源 alpha 解码编号（< 0.05 视为覆盖，最近邻取整），五条曲线与既有单算子片元逐式一致；全局算子经推送常量 offset 96 的 w 下发为回落值，算子 5（双轨）保留区域过渡。

- 新增用例 `Scene.PBR逐材质色调算子同帧`：左 AgX / 右 ACES 纯蓝同帧 —— ACES 侧通道差 **≥120**、AgX 侧低至少 30；未覆盖材质与显式 ACES 帧逐字节一致。

## 第 784 轮 · 收窄逐材质色调编号的 alpha 编码

- 779 的编码 `(id+1)/255` 会与粒子等透明绘制的 alpha 碰撞（解码阈值 0.05），把非材质对象误判为材质覆盖。

## 第 797 轮 · 8 位路径逐材质色调预研（文档轮）

- 结论：8 位 alpha 仅 256 级，`(id+1)×0.0005` 全量化为 0——是通道缺失而非精度取舍。
- 推荐方案 A：`R8` 第二颜色附件（MRT）专写编号，末级用 `usampler2D` 读取；16F 路径同样受益；
  读取优先级 id 附件 > alpha > 全局。分四段（资源 / 管线 / 场景 / 末级）落地并给出每段验收。
- 方案 B（独立 id 预通道）不划算；现状 C 已由 794 告警 + 用例兜住。
