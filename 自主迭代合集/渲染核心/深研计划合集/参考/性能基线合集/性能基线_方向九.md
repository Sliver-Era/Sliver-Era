# 性能基线 · 方向九（PBR 写实与二次元融合）

> 建立日期：2026-11-17（第 712 轮）
> 用例：`Application/Test/tests/Renderer/src/渲染PBR性能基线测试.cpp`
> 口径：CPU 侧 `frame_render` 中位耗时（3 帧预热 + 20 帧取样），`vsync = false`、`validation = false`；不读回像素。
> 说明：本文件只记录 PBR 相关开销，GPU 时间戳未纳入；IBL / HDR 落地后按同口径复测。

## 一、实例规模（640 × 360）

| 实例数 | Debug 关 PBR (ms) | Debug 开 PBR (ms) | Release 关 PBR (ms) | Release 开 PBR (ms) |
| --- | --- | --- | --- | --- |
| 1 | 0.289 | 0.261 | 0.264 | 0.242 |
| 100 | 0.290 | 0.267 | 0.214 | 0.215 |
| 1000 | 0.275 | 0.255 | 0.248 | 0.225 |

结论：1 → 1000 实例在当前分辨率下未见可测增长（差异 < 0.05 ms，处于噪声内）；PBR 开关同样未见稳定方向性差异。说明当前瓶颈不在实例属性上传或 PBR 分支，而在固定帧提交开销。

| 组合 | Debug (ms) | Release (ms) |

结论：Debug 各组合差异 < 0.03 ms；Release 差异 < 0.06 ms（环境 BRDF 略高但仍在噪声与调度波动内）。
新增分支未引入可测 CPU 开销（GPU 侧未纳入）；强光照压力场景 Release 0.264 ms。

## 四、复测口径

- 命令：`TestRenderer.exe --gtest_filter=Renderer_Scene_Test.PBR* --gtest_output=json:<ASCII 路径>`
- Debug / Release 各跑一次，取中位；报告写「相对基线 ±%」，无性能面写「无」。
- 新增 PBR 路径必须默认关闭，并同时记录关闭 / 开启两组数值。

## 逐材质 PBR 特性开销（第 782 轮 · 通用引擎化整改）

> 口径：640×360、1000 实例、全局特性全关，仅比较「材质不覆盖」与「材质掩码全开（bit0..4）」；
> 中位帧耗时（含 3 帧预热 / 20 帧采样），vsync 与校验层关闭。用例 `Scene.PBR逐材质特性开销`。

| 配置 | Debug（ms） | Release（ms） |
| --- | --- | --- |
| 材质不覆盖（基线） | 0.2351 | 0.2117 |
| 材质掩码全开（5 项特性） | 0.2774 | 0.2436 |

结论：逐材质位掩码路径只增加一次位判定与相应着色分支，Release 增量约 0.03 ms / 1000 实例；
与整改前全局特性的 0.224–0.294 ms 区间同量级，未出现数量级劣化。实例步长 112 → 128 字节的带宽增量未在 CPU 侧体现为显著开销。
