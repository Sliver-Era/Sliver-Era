# 深研规划 · 方向九：PBR 写实与二次元融合（2026-11-17 立项）

> 服务核心使命：**3D 风格、多物体写实画风、人物二次元风格、较强光照表现的游戏**。
> 起点：第 709 轮（方向八光照与阴影收口）；本方向自第 710 轮起，跨窗口延续。
> 原则：所有新增路径默认关闭、关闭时逐字节不变；每轮用结构化像素指标 ＋ 性能基线验收。

## 一、现状审计（第 709 轮）

已具备：

- PBR-lite 开关与全局参数：`pbr_enabled` / `pbr_roughness` / `pbr_metallic`；逐物体覆盖 `Material_Data::pbr_override`。
- BRDF：GGX 分布 ＋ Smith-Schlick 几何项 ＋ Schlick 菲涅尔；F0 = mix(0.04, albedo, metallic)。
- 能量修正：掠射高光乘 NoL（`pbr_energy`）、漫反射菲涅尔分摊（`pbr_diffuse_energy`）、粗糙度绝对口径（`pbr_roughness_absolute`）。
- 贴图：法线 / 粗糙度 / 金属度 / AO / 自发光；逐物体清漆（`clearcoat`）。
- 光照：方向光 ＋ 补光 ＋ 32 盏点 / 聚光、簇路径、阴影 / PCSS / 接触阴影、体积光 / 体积雾。
- 后处理：泛光、色调映射（Reinhard / 指数）、曝光补偿、调色、SSAO、SSR、景深、FXAA。

主要缺口（按对核心使命的影响排序）：

1. **无环境光照（IBL）**：金属与粗糙材质缺少环境反射 / 漫反射辐照度，写实感与强光照表现受限。
2. **BRDF 仍为单次散射近似**：无多重散射能量补偿，高粗糙金属偏暗；无镜面抗锯齿，远处高光闪烁。
3. **材质域偏窄**：缺各向异性（头发 / 拉丝金属）、皮肤 SSS-lite、布料清漆 / 绒感、透明与折射。
4. **HDR 管线不完整**：中间目标以 LDR 为主，色调映射算子只有 Reinhard / 指数，缺 ACES / AgX 类胶片曲线与色彩管理。
5. **二次元与写实双轨未统一**：toon 参数与 PBR 参数并存，缺少「人物二次元、场景写实」的材质分层与统一光照口径。
6. **多物体性能预算未系统化**：材质切换、描述符更新、实例缓冲与 PBR 贴图采样的开销缺基线。

## 三、验收口径

- **默认关闭逐字节不变**：所有新增路径一键关闭，旧画面逐字节一致。
- **像素指标**：中心亮度、亮像素数、差异像素数、压暗 / 提亮计数；不硬编码单点颜色。
- **性能**：对照 `性能基线_方向九.md`，每轮写「相对基线 ±%」；无性能面写「无」。
- **测试**：每轮新增能力同时补数据侧断言与至少一条 E2E；纯数据逻辑优先无 GPU 用例。
- **外部库**：优先自研；引入须记录来源 / 版本 / 许可并放各层 `external/`。

## 四、风险

1. IBL 资源与显存开销大，需默认关闭并做容量上限。
2. 着色器 `场景.frag` 已 56 KB，新增分支会放大编译与回归成本；阶段 B 起评估拆分或 include 组织。
3. HDR 链路影响面广（目标格式、后处理、UI 混合），需逐段开关。
4. 二次元与写实双轨容易出现口径分裂，阶段 F 前先定「材质声明 → 着色分支」单一来源。
