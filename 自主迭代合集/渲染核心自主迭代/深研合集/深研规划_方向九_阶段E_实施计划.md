## 二、AgX 近似实现口径（736）

- 输入：`texelFetch(source_image, coord, 0).rgb`，先 `max(color, 0)`。
- 3×3 输入矩阵（sRGB → AgX 工作空间）→ 对数压缩曲线 → 3×3 输出矩阵（AgX → sRGB）。
- 参数：`post_param.x` 作为「对比度 / look」占位，默认 0（标准 AgX）；不改推送块布局。
- 验收：同一输入下 AgX 与 ACES 在 0.18 / 1.0 / 0.5 三档的输出差异可测；高光滚降更柔；
  画面无通道反转（R/G/B 最大值单调不减）。

## 三、HDR 中间目标口径（738）

- `Renderer_Config` 增 `hdr_targets`（默认 false）。
- 目标格式：启用时场景色附件与后处理链中间目标用 `VK_FORMAT_R16G16B16A16_SFLOAT`；MSAA 解析目标同格式。
- 读回：`frame_render` 仍输出 RGBA8，内部做 `clamp(x,0,1)` 后 sRGB 编码；关闭态路径不变。
- 验收：开启后高光球中心不截断（中间目标读回 > 1 的像素计数 > 0）；关闭态全部用例逐字节不变。

## 四、风险与前置检查

1. 目标格式改动会影响所有 `frame_render` 用例的读回口径，需确认 8 位转换在两条路径一致（关闭态逐字节）。
2. MSAA 4× 的 16F 解析目标显存翻倍；先测 1× / 4× 两组显存与帧耗时再定默认。
3. UI 通道混合公式在 sRGB 与线性 16F 之间不同，需单独用例覆盖。
4. 后处理链多级传递时格式需逐级一致，避免中途降级为 8 位。
