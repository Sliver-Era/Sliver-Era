## 第 751 轮 · 导航回写：自绘控件树与 UI 事件桥

- 起因：用户询问「UI 子对象如何接入事件系统」，导航仅有 `Ui_Event_Bridge` 一行提及，无法解答。
- 回写内容：`Ui_Context`（保留模式控件树、控件不持终端）→ `Input_Frame` 每帧交互 → 唯一 `Ui_Event_Bridge`（内含唯一 `Event_Terminal`）接入 `Event_Broker`；
  出站 5 类（Raw / MouseFocus / ChildFocus / ModalPush-Pop / TextSession）、入站 4 类（FocusChanged / TextMode / Command / Text）与桥内去重、焦点确认、未消费外溢；
  并区分「ImGui 透传通道 `Ui_Channel_Context`」与「引擎自绘控件树」两套路径。
- 代码零改动；外部库无变更。

## 第 767 轮 · HDR 泛光组合矩阵（修复上钳吞高光）

- 新增组合矩阵用例（1x / 4x × 泛光 × 半分辨率，六组合）—— 首跑即失败：**开泛光后主体更暗**（中心 252 → 232）。
- 根因：`泛光叠加.frag` 的 `clamp(scene + bloom, 0, 1)` 在 HDR 链路上把 4.0 的高光压到 1.0，色调映射后反而低于不开泛光。
- 修法：改为 `max(scene + bloom, 0.0)`（只钳下界）。16F 宿主保留高光（中心 **255**），8 位宿主写入时自然饱和、行为不变。
- 矩阵结果：级数 1（无泛光）/ 4（泛光）、采样数 1 / 4 如实上报、中心亮度跨组合最大差 **3**。
- 着色器同步教训：`.spv` 是 Renderer 的**构建期**目标（改 `.frag` 必须构建，仅重配无效）；Test 在**配置期**从 Renderer 构建树拷贝且优先取 Release 树，Release `.spv` 陈旧会把旧着色器带进测试。
- 后处理链 **122 / 122**；渲染层全套 **824 / 824**（359.1 s）；非渲染层 **783 / 783**；Release 后处理链 **122 / 122**（59.1 s）、渲染层 **824 / 824**、非渲染层 **783 / 783**；Renderer `df61060` / Test `2a01694`。
