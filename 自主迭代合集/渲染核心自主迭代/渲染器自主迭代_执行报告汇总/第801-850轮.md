## 第 801 轮 · 渲染目标可选色调编号附件（8 位 MRT 段 1）

- `target_create` 增加 `tone_id_format`；单采样时创建 `R8_UINT` 附件（颜色附件 ＋ 采样）并纳入初始布局转换。
- 门面新增 `render_target_create_format_ex` 与 `render_target_tone_id_get`；原接口行为不变。
- 首跑暴露 VMA「Unfreed dedicated allocations」：门面延迟释放队列补入编号附件条目后通过。
- 验证：Debug / Release 零错误；`Renderer_Offscreen_Test.*` **12 / 12**。Renderer `3405abd` / Test `d59a5e6`。

## 第 808 轮 · 逐材质色调编号预通道（8 位路径方案 B）

- 代码版次：Renderer `bee8547` / Test `08ace98`（两仓已推送）。

  `render_target_readback_tone_id` 每像素 1 字节读回。
- 资源：编号附件补 `TRANSFER_SRC` 用法（读回必需）。
- 用例 `Offscreen.逐材质色调编号预通道`：中心 1（ACES）、边缘 5（AgX）；反转绘制顺序后中心仍为 1。
