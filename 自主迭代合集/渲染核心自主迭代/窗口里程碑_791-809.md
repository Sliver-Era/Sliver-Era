## 三、关键结论

1. **MRT 路线在本引擎不可行**：动态渲染要求同一 pass 内全部管线声明相同附件数（天空盒 / 粒子 / UI / 描边均单附件），变体成本远高于收益。
2. **独立 id 预通道可行且零侵入**：主 pass 保持单颜色附件；编号通道以同一深度重绘，只标记最终可见片元；开关默认关、管线懒登记，资源计数与既有画面不变。
3. **默认零影响是可测属性**：809 用例把「开关不改变画面」固化为回归守卫。
4. **下一段（段 4）已有可执行设计**：采样集补 binding 10 ＋ 默认 `R8_UINT` 零图 ＋ `usampler2D` 解码；需统一覆盖全部采样集写出点。
