# 游戏层自主迭代

> 主体：《Sliver-Era》本作（工作区 `Application/Game/Sliver-Era`）。
> 轮次从第 1 轮起独立计数，不与渲染核心混排。

## 目录

- `计划分册/`：每 25 轮一份执行计划（`第001-025轮.md` …）。
- `报告分册/`：每 25 轮一份执行报告，与计划同区间。
- `索引/`：`索引_001-500.md` 起分层存放，记录分层清单与轮次索引。
- `里程碑/`：窗口里程碑记录。
- `下轮迭代方向.md`：下一轮迭代方向（进入自主迭代后书写）。
