## 一、方向

「游戏框架搭建」阶段 D 第 16 轮：**方块拾取与交互**。

玩家已经能移动、转向与切换相机，但世界仍是只读的。本轮加入体素 DDA 射线检测，
把命中结果接到破坏/放置请求，并在修改后重建受影响区块网格。

## 二、工作内容

1. `方块射线` 纯函数（DDA / Amanatides-Woo）：
   - 输入起点、方向、最大距离与世界方块查询；
   - 输出 `射线命中 { 是否命中, 方块坐标, 进入面法向, 距离 }`；
   - 起点所在方块先检测；跳过空气与水；越界查询按空气；
   - 最大距离按步进累计，超出即未命中。
2. `方块交互` 纯函数：
   - `方块破坏(区块管理器&, 坐标)`：固体方块改为空气，返回是否改动；
   - `方块放置(区块管理器&, 坐标, 类型)`：仅当目标为空气/水且区块已加载时写入；
   - `命中破坏(区块管理器&, 命中)` / `命中放置(区块管理器&, 命中, 类型)`：放置坐标 = 命中坐标 + 法向。
3. `游戏应用` 接入：
   - 鼠标左键按下沿破坏、右键按下沿放置（草方块）；
   - 射线起点 = 相机眼点，方向 = 注视点 - 眼点，最大 6 格；
   - 修改后重建目标区块网格；若修改点在区块边界，同时重建相邻区块（面剔除需要）。
4. 自检 `--interact-test`：
   - 垂直向下射线命中 y = 0 方块，法向 +Y；
   - 水平射线命中指定方块，法向与进入方向相反；
   - 空世界未命中；
   - 最大距离不足时未命中；
   - 负坐标世界正确命中；
   - 破坏后方块变空气，重复破坏返回假；
   - 放置仅在空气/水处成功，坐标 = 命中 + 法向；
   - 纯数据，不初始化渲染器。

## 三、验收口径

- Debug / Release 双配置构建零错误。
- `--interact-test` 与既有十四条自检（camera / input / player / entity / meshgen / chunk / voxel / self / state / module / config / path / resource / log）均返回 0。
- `--self-test` 正常退出；未点击时世界不变。
- 射线方向复用相机方向约定，命中法向写入文档。

## 四、风险与回退

- 射线检测只做体素步进，不做细粒度三角形检测；方块为轴对齐单位立方体。
- 放置不检查玩家碰撞，可能把方块放进玩家身体；碰撞完善前只做单点放置。
- 修改边界方块会触发相邻区块重建，若性能异常可先只重建目标区块（面剔除留缝可接受）。
