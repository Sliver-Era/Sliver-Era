# 下轮迭代方向（第 11 轮）

> 书写时间：2026-11-21 ｜ 方向：游戏框架搭建（方向深研轮） ｜ 上一轮终态：工作区 `c68acc4396faca3ff162d9735fcc1f8bacf05292`，阶段 C 第 10 轮区块管理器完成。

## 一、方向

「游戏框架搭建」阶段 C 第 11 轮：**区块网格生成与渲染接入**。

第 10 轮已有可遍历的多区块集合，但世界里没有任何可见几何体。本轮把区块数据转成引擎网格
（隐藏面剔除 + 六向面片），接入渲染器并在主循环绘制，同时补齐邻接区块更新入口。

## 二、工作内容

1. 纯函数 `区块网格生成`：
   - 输入 `区块数据` 与可选的邻接查询（跨区块邻居），输出 `engine::Mesh_Data`；
   - 六向面剔除：邻居为固体方块时不生成该面；本区块外按未加载/空气处理；
   - 面片写入位置、法线与 UV，索引按逆时针绕序；
   - 空区块输出空网格（顶点与索引均为空），由调用方跳过绘制。
2. 固体判定：`方块类型` 增加 `方块类型是固体`（空气与水返回假），供面剔除与后续碰撞复用。
3. 网格集管理 `区块网格集`：
   - 区块坐标 → 网格句柄 + 脏标记；
   - `网格重建(x,y,z)`：按当前区块数据重建，旧句柄先卸载再创建；
   - `网格释放(x,y,z)`、`清空`；渲染器未绑定时拒绝重建并记录错误。
4. 渲染接入：
   - `游戏应用` 初始化时为已加载的 9 个区块生成网格；
   - `frame_draw` 按区块坐标平移绘制，颜色暂用草色；
   - `shutdown` 先释放网格集，再关闭渲染器。
5. 场景基线用体素地面替换程序化地面：中心 9 个区块各铺一层草方块（y=0），验证多区块可见。
6. 自检 `--meshgen-test`：
   - 单方块 6 面 → 24 顶点 / 36 索引；
   - 两相邻方块共面剔除 → 10 面；
   - 16³ 全实心仅外表面 1536 面；
   - 空区块网格为空；
   - 法线与索引绕序合法（索引不越界、每面 4 顶点 6 索引）；
   - 纯数据，不初始化渲染器。

## 三、验收口径

- Debug / Release 双配置构建零错误。
- `--meshgen-test` 与既有九条自检（chunk / voxel / self / state / module / config / path / resource / log）均返回 0。
- `--self-test` 日志显示区块网格数量 9（体素地面非空），退出无资源泄漏。
- 面剔除规则与索引绕序写入文档，后续材质与光照直接复用。

## 四、风险与回退

- `Mesh_Data` 顶点数超过引擎单网格上限时创建失败：首版按区块生成，16³ 全实心 24576 顶点可控。
- 9 个区块每帧 9 次 draw 可接受；区块网格不合并，避免过早引入批处理。
- 体素地面替换程序化地面属于场景基线变更，若绘制异常可直接回退到 `scene_build` 的旧地面路径。
