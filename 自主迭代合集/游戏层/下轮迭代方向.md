# 下轮迭代方向（第 15 轮）

> 书写时间：2026-11-21 ｜ 方向：游戏框架搭建（方向深研轮） ｜ 上一轮终态：工作区 `2323522070730f083bf0f2ddc6efd87f7c263ce1`，阶段 D 第 14 轮输入层完成。

## 一、方向

「游戏框架搭建」阶段 D 第 15 轮：**第一人称 / 第三人称相机控制与切换**。

玩家已经能移动与转向，但相机仍是配置里的固定机位。本轮建立相机状态与跟随逻辑，
把玩家位置/朝向接到渲染器相机，并提供 F5 切换第一/第三人称。

## 二、工作内容

1. `相机状态`：眼点位置 `position[3]`、注视点 `target[3]`、视场角、模式（第一人称 / 第三人称）、第三人称距离。
2. `游戏相机` 纯逻辑类：
   - `第一人称更新(玩家状态, dt)`：眼点 = 脚底 + (0, 1.6, 0)；方向由偏航/俯仰得出，注视点 = 眼点 + 方向；
   - `第三人称更新(玩家状态, dt)`：目标点 = 脚底 + (0, 1.4, 0)；眼点 = 目标点 - 方向 × 距离，带平滑跟随；
   - `模式切换()` / `模式设置()`：第一 ↔ 第三人称；
   - 距离钳制到 [1.5, 8.0]，视场角钳制到 [30°, 110°]。
3. 输入接入：F5 按下沿切换相机模式（按键沿由输入层缓存上一帧状态实现）。
4. `游戏应用` 每帧绘制前把相机状态写入 `renderer.scene()`（位置、注视、视场角）。
5. 自检 `--camera-test`：
   - 初始为第一人称；
   - 偏航 0、俯仰 0 时注视方向为 -Z；
   - 偏航 π/2 时注视方向为 -X；
   - 俯仰 ±89° 时方向 Y 分量符号正确；
   - 第三人称眼点在目标点后方，距离等于设置值；
   - 距离与视场角钳制生效；
   - 平滑跟随在一次更新后向目标靠近但不越界；
   - 模式切换往返正确；
   - 纯数据，不初始化渲染器。

## 三、验收口径

- Debug / Release 双配置构建零错误。
- `--camera-test` 与既有十三条自检（input / player / entity / meshgen / chunk / voxel / self / state / module / config / path / resource / log）均返回 0。
- `--self-test` 正常退出；相机由玩家状态驱动，不再使用配置固定机位。
- 相机方向约定写入文档，后续方块射线检测直接复用。

## 四、风险与回退

- 第三人称不做遮挡检测，眼点可能穿入方块；遮挡回缩留到方块交互轮次。
- 相机平滑只做位置插值，不做旋转插值；避免引入额外状态。
- 若相机切换引入异常绘制，可直接回退到固定机位路径（保留配置读取）。
