# 下轮迭代方向（第 13 轮）

> 书写时间：2026-11-21 ｜ 方向：游戏框架搭建（方向深研轮） ｜ 上一轮终态：工作区 `bc6077309d0a0c0809329d4a30e05c2b1dd93551`，阶段 C 第 12 轮实体/组件注册表完成。

## 一、方向

「游戏框架搭建」阶段 C 第 13 轮：**玩家实体与基础移动**。

实体系统已有容器与更新调度，但没有任何真实实体。本轮用玩家组件落地位置、朝向、速度与
最小碰撞占位（地面钳制），并以玩家状态驱动场景中的占位方块，形成「实体 → 渲染」链路。

## 二、工作内容

1. `玩家状态`：脚底位置 `position[3]`、偏航 `yaw`、俯仰 `pitch`、速度 `velocity[3]`、是否着地 `on_ground`。
2. `玩家组件 : 组件`：
   - `状态获取`（只读/可写）；
   - `速度设置`、`朝向设置`（偏航归一到 [-π, π]，俯仰钳制到 ±89°）；
   - `更新(dt)`：水平速度按 10/s 衰减；垂直速度受 9.8 m/s² 重力；位置积分；
   - 地面钳制：脚底 `y >= 1.0`（当前体素地面高度），触地时清零垂直速度并置 `on_ground`。
3. `玩家创建(实体注册表&)`：创建实体并挂载玩家组件，返回实体指针（失败返回空）。
4. `游戏应用` 接入：
   - 初始化创建玩家实体，脚底默认 `(0, 1, 0)`；
   - 占位立方体改为按玩家位置与偏航绘制（不再随时间自转）；
   - 关闭时清空实体表（已有）。
5. 自检 `--player-test`：
   - 玩家创建成功且组件名称为「玩家」；
   - 初始状态位置、着地标记正确；
   - 设置水平速度后更新，位置按速度与摩擦变化，速度衰减；
   - 垂直速度受重力，落地后 `y = 1`、垂直速度为 0、`on_ground` 为真；
   - 偏航归一化（3π/2 → -π/2）；
   - 俯仰钳制（±2.0 → ±89°）；
   - 未挂载玩家组件的实体返回空；
   - 纯数据，不初始化渲染器。

## 三、验收口径

- Debug / Release 双配置构建零错误。
- `--player-test` 与既有十一条自检（entity / meshgen / chunk / voxel / self / state / module / config / path / resource / log）均返回 0。
- `--self-test` 正常退出，占位立方体位于玩家位置，绘制项数量不异常增长。
- 地面高度常量集中定义，后续地形生成只需替换该常量来源。

## 四、风险与回退

- 本轮不做方块碰撞与射线检测，地面钳制是临时占位；第 27 轮方块交互再替换为真实碰撞。
- 玩家更新依赖固定步长，禁用组件或禁用实体时不得移动。
- 占位立方体改为玩家驱动后，原先「自转验证更新解耦」的观感消失，但更新次数与帧统计仍可验证。
