# 下轮迭代方向（第 5 轮）

> 书写时间：2026-11-21 ｜ 方向：游戏框架搭建（方向深研轮） ｜ 上一轮终态：工作区 `21260b7b`，阶段 A（应用骨架与主循环）四轮完成。

## 一、方向

「游戏框架搭建」阶段 B 第 5 轮：**游戏配置 JSON 加载**。

阶段 A 已具备应用生命周期、固定步长、状态机与模块调度；但配置仍全部硬编码在 `应用配置` 默认值与命令行中。
本轮把窗口、渲染、相机、场景参数落成 JSON 配置，建立「默认值 → JSON → 命令行」的覆盖链，为后续画质/键位/世界配置打底。

## 二、工作内容

1. 配置 schema（首版）：
   - 窗口：宽度、高度、标题、垂直同步；
   - 渲染：多重采样、帧率上限；
   - 相机：位置、注视、视场角、近平面、远平面；
   - 场景：清屏色、光照方向/颜色/强度、环境光。
2. 新增 `配置加载(应用配置&, 路径)`：
   - 文件缺失：记录警告并保留默认值，不视为致命错误；
   - 字段缺失：保留默认值；
   - 非法值（越界、数组长度不符、类型不符）：归一或回落默认值并记录警告。
3. 覆盖链：默认值 → JSON → 命令行；命令行始终优先。
4. 默认配置文件：`assets/config/游戏配置.json`，构建后复制到可执行文件同目录。
5. 路径处理：按可执行文件目录解析，中文路径经引擎路径工具转换，不依赖当前工作目录。
6. 自检 `--config-test`：
   - 加载默认配置并核对关键字段；
   - 加载不存在文件，核对默认值未被破坏；
   - 加载非法值配置，核对归一结果与警告。

## 三、验收口径

- Debug / Release 双配置构建零错误。
- `--self-test`、`--state-test`、`--module-test`、`--config-test`、`--updates 120 --hidden` 均返回 0。
- 缺少配置文件不影响启动；非法字段不会导致崩溃。
- 命令行覆盖 JSON 的结果在启动日志中可见。

## 四、风险与回退

- 配置字段命名一旦写入存档/文档就难改；本轮字段使用中文键，后续只增不改，删除需保留兼容读取。
- JSON 解析依赖 nlohmann/json（由 Engine 对外接口提供包含根），不新增外部库。
- 中文路径在 MSVC 下需宽路径转换；若引擎路径工具不可用，退回 ASCII 相对路径并在日志中提示。
