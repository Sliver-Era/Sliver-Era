# 下轮迭代方向（第 7 轮）

> 书写时间：2026-11-21 ｜ 方向：游戏框架搭建（方向深研轮） ｜ 上一轮终态：工作区 `b6f7fee6`，资产路径与目录规范落地。

## 一、方向

「游戏框架搭建」阶段 B 第 7 轮：**网格资源缓存与引用计数**。

第 6 轮打通了资产路径，但网格仍由 `游戏应用` 直接加载/卸载，重复获取会重复上传显存。
本轮建立最小资源缓存：键 → 句柄 + 引用计数，归零才卸载，为后续区块、角色、道具共用资源打底。

## 二、工作内容

1. 新增 `资源缓存`：
   - `网格获取(键)`：命中则引用 +1 并返回句柄；未命中则加载、登记引用 1；
   - `网格释放(键)`：引用 -1；归零时卸载网格并移除条目；
   - `网格条目数()`、`关闭()`。
2. 键规范（首版）：
   - 程序化键：`@地面`、`@立方体`；
   - 资产键：`assets/meshes/立方体.obj`（相对资产根）。
3. 加载失败不登记，返回 0；同一键加载失败后允许重试。
4. `游戏应用` 改用资源缓存获取/释放基线网格，移除直接 `mesh_ground_grid_load` / `mesh_cube_load` 调用。
5. 新增 `assets/meshes/立方体.obj` 作为路径加载夹具。
6. `--resource-test`：
   - 同键两次获取 → 引用 2、条目 1；
   - 释放一次 → 引用 1、条目仍 1；
   - 再释放 → 引用 0、条目 0；
   - 缺失资产获取返回 0 且不登记。

## 三、验收口径

- Debug / Release 双配置构建零错误。
- `--resource-test`、`--path-test`、`--config-test`、`--self-test`、`--state-test`、`--module-test` 均返回 0。
- 重复获取不重复加载（日志与条目数可证）。
- 引用归零后网格真正卸载。

## 四、风险与回退

- 缓存键必须规范化（分隔符、大小写、相对路径），否则同一资产会被重复登记；本轮统一转为 `/` 分隔并拒绝绝对路径。
- 引用计数下溢视为错误并记录，不静默回绕。
- 资源缓存不拥有渲染器；渲染器关闭前必须先 `关闭()` 缓存，避免句柄悬空。
