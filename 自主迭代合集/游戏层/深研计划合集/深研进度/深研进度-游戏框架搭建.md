## 第 1 轮：应用骨架与主循环

### 一、实际修改内容

新增：
- `src/框架/应用配置.h`：窗口、渲染、相机、清屏色与光照配置；命令行解析接口。
- `src/框架/游戏应用.h`：`游戏应用` 类（init / run / shutdown）。
- `src/框架/core/应用配置.cpp`：`--width`、`--height`、`--frames`、`--hidden`、`--self-test` 解析。
- `src/框架/core/游戏应用.cpp`：渲染器初始化、相机/光照/清屏色、地面与立方体网格、主循环、退出统计。
修改：
- `src/主调/主程序.cpp`：接入配置解析与游戏应用生命周期。
- `CMakeLists.txt`：加入 `src/`、`src/框架/` 包含根。

### 二、验证结果

- Debug 构建通过；`SliverEra.exe --self-test` 返回 0，隐藏窗口推进 3 帧后正常退出。
- Release 构建通过；`SliverEra.exe --self-test` 返回 0。
- Debug `--frames 5 --hidden`（MSAA 4× 路径）返回 0。
