# 深研预研-游戏框架搭建

> 方向：游戏框架搭建 ｜ 记录方式：每轮开发前预研，开发后回填实测

## 第 1 轮：应用骨架与主循环

### 一、当前迭代轮开发内容

建立游戏侧最小应用骨架：
1. 应用配置结构与命令行覆盖。
2. `游戏应用` 生命周期：初始化渲染器、构建场景基线、主循环、关闭。
3. 场景基线：地面细分网格 ＋ 基准立方体，确认渲染链路可用。
4. `--self-test` / `--frames` / `--hidden` 自检入口。

### 二、当前源码实现

本轮前工作区仅有 `src/主调/主程序.cpp` 的占位实现：设置日志根目录、输出一行日志后返回。
引擎侧可用能力（来自 `external/Engine` 公共头）：
- `engine::Renderer::init(Renderer_Config)`、`frame_render()`、`close_requested()`、`frame_stats_get()`。
- `Renderer::scene()`：相机位置/注视/视场角/近远平面、清屏色、方向光。
- `Renderer::resource()`：`mesh_ground_grid_load`、`mesh_cube_load`、`mesh_draw`、`mesh_unload`。

### 三、预计修改方式

新增文件：
- `src/框架/应用配置.h`：配置结构与 `配置解析`。
- `src/框架/游戏应用.h`：应用类声明。
- `src/框架/core/应用配置.cpp`：命令行解析实现。
- `src/框架/core/游戏应用.cpp`：初始化、场景基线、主循环、绘制、关闭与变换矩阵。
修改文件：
- `src/主调/主程序.cpp`：改为解析配置 → 构造应用 → 初始化 → 运行 → 关闭。
- `CMakeLists.txt`：为 `src/` 与 `src/框架/` 增加包含根（保持引擎快照在前）。

风险与回退：
- 渲染器初始化依赖 Vulkan 设备；失败时记录错误并返回非 0。
- 场景基线只使用程序化网格，不依赖资产文件；若网格接口不可用，回退为仅清屏并保留框架。

## 第 9 轮：体素方块数据模型

### 一、当前迭代轮开发内容

建立世界侧最小体素数据结构：
1. 六类方块枚举。
2. 16³ 区块数据：坐标、读写、填充、计数。
3. 线性索引约定与三维坐标互转。
4. 纯数据自检 `--voxel-test`。

### 二、当前源码实现

本轮前工作区只有框架层（应用配置、路径、资源缓存、日志）与 `src/框架/游戏模块.h` 的空壳世界模块，没有任何世界数据结构。
`游戏应用` 的场景基线仍为程序化地面与单个立方体，不与世界数据关联。

### 三、预计修改方式

新增：
- `src/世界/体素类型.h` / `core/体素类型.cpp`：`方块类型`（`uint8_t` 底层）与名称。
- `src/世界/区块数据.h` / `core/区块数据.cpp`：`std::array` 固定存储、越界安全接口、索引互转。
- `src/世界/core/体素自检.cpp`：纯数据自检。
修改：
- `src/框架/应用配置.h/.cpp`：`体素自检` 与 `--voxel-test`。
- `src/主调/主程序.cpp`：日志初始化后直接执行体素自检并返回。

风险与回退：
- 索引顺序一旦进入存档就难改，首版固定 `x + z * 16 + y * 256` 并写入用例。
- 纯数据层不得引入渲染或文件 IO，网格生成顺延至第 11 轮。
