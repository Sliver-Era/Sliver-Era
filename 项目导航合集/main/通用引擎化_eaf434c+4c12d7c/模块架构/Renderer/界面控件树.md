## 一、模块功能

引擎自绘 UI 由三部分组成：

1. `Ui_Context`：**保留模式控件树**。控件类型 `Root / Panel / Button / Text_Box / Label / Checkbox / Slider`；
   按创建顺序存放、逆序命中；每帧消费一份 `Input_Frame` 快照完成悬停 / 按下 / 点击 / 焦点 / 文本编辑 / 拖动。
2. `Ui_Local_Bus`：UI **域内局域网**的中心路由。内部节点经端口级联接入，域内事件（`UI/*`）只在此派发；
   不 attach 事件中转站，外部模块结构上订阅不到。
3. `Ui_Event_Bridge`：**边界网关**，也是 UI 唯一的外部事件接触面。它把一个 `Event_Terminal` 接入事件系统，
   按白名单把域内事件翻译为 `Input/*` 送出，并把系统事件收敛后映射回控件 / 域内总线。

控件结果先作为 `UI/*` 域内事件进入本地总线，再由网关翻译为 `Input/*`；
`on_click / on_toggle / on_value` 回调保留，等价于「只订阅自己」的本地快捷路径。

## 三、私有成员与内部状态

`Ui_Event_Bridge` 私有状态：

| 成员 | 作用 |
| --- | --- |
| `subscriber` / `acl_key` / `attached_flag` | 订阅者名、权限密钥、接入标记 |
| `focus_main / focus_child / focus_modal` | 系统焦点缓存（来自 `FocusChanged`） |
| `text_mode` | 系统文本模式（来自 `TextMode` / `FocusChanged`） |
| `commands` / `texts` | 未消费的语义命令 / 文本队列 |
| `last_modal` / `last_preedit` / `last_focus_name` | 变化去重 |
| `pending_focus` / `pending_active` / `pending_age` | 焦点上报后的确认窗口（防回声） |
| `bound_ui` | 已绑定域内总线的 UI 上下文（网关翻译需要 `command_of`） |

`Ui_Context` 私有状态：控件集合 `nodes`（句柄 = 下标 + 1）、`hovered / pressed / focused / slider_drag`、
UI 主对象名 `input_root_name`、点击外部目标名 `input_outside_name`、模态根名 `modal_input_name`、
本帧按下名 `pressed_input_name`、`press_outside / press_any`、命令绑定表 `command_bindings`、键盘总闸 `keyboard_gate`、
域内总线 `local_bus`（`unique_ptr<Ui_Local_Bus>`，构造时创建）。

## 四、内部架构

```
应用层 / 渲染层界面域
   └─ Render_UI_State
        ├─ Ui_Context（控件树）
        │     └─ Ui_Local_Bus（域内中心终端；不接 Broker）
        │           ├─ 内部节点发送端口（端口级联）
        │           └─ 订阅者（应用层 / 测试 / 网关翻译器）
        ├─ Ui_Event_Bridge（边界网关）
        │     └─ Event_Terminal（唯一外部接触面；接 Event_Broker）
        └─ Ui_Renderer / Font_Context / Input_Aggregator
```

- 帧内顺序固定为：`ui_event.text_route_prepare(ui)`（幂等绑定域内总线）→ `ui.frame_begin(frame)`（末尾派发域内事件）
  → `ui_event.frame_publish(frame, ui)` → `ui_event.frame_apply(ui)`（末尾再次派发）。
- 事件方向见 §七：域内 `UI/*` 只走本地总线；出站 5 类 ＋ 网关翻译的 `Input/Command`；入站 4 类。

## 五、设计细节

1. **域内局域网，而非全局总线**：控件事件先进入 `Ui_Local_Bus`（中心 `Event_Terminal` ＋ 端口级联），只在本域派发；
   `Ui_Event_Bridge` 是唯一出口，按白名单翻译为 `Input/*`。域内事件不登记 Broker，外部模块结构上订阅不到。
2. **入口同步、派发在遍历后**：控件在 `frame_begin` 的命中 / 交互过程中只入队，遍历结束后统一派发；
   派发期间新产生的事件留到下一轮，避免改树打断遍历。
3. **防环**：网关翻译产物带 `origin = "gateway"`，网关不再回译；`command_dispatch` 激活控件时同样带该标记。
4. **出站按变化发送**：`MouseFocus` 只在左键按下沿发；`ModalPush/Pop` 只在模态根变化时发；
   `ChildFocus` 只在本地焦点变化且非按下帧时发；`TextSession` 只在提交或预编辑变化时发。
5. **焦点防回声**：上报后进入 `pending_active`；系统确认（`focus_child == pending_focus`）才恢复跟随；
   连续 2 帧未确认视为拒绝；期间不跟随系统回写，避免系统一帧延迟把本地 Tab 导航顶回。
6. **键盘总闸**：系统焦点不在 UI 主对象时关闭控件键盘消费（鼠标交互不受影响）；未配置主对象名时保持开启，支持独立使用。
7. **文本双路**：系统文本模式关闭时文本框本地拼接；开启且焦点控件已绑定系统输入名时走 `TextSession`，由系统回传落文本。
8. **未消费外溢**：命令 / 文本先由控件消化，消化不掉才留在队列供应用层 `command_pop / text_pop`。
9. **模态归属**：`ModalPush/Pop` 的 sender 固定为本订阅者，满足焦点系统的归属校验。
10. **悬停只域内**：悬停目标变化发 `UI/Hover`（连续同目标不重复），不翻译为 `Input/MouseFocus`——焦点语义仍由按下沿决定。

## 六、运行链路详例

### 6.1 点击一个按钮

1. `ui.frame_begin(frame)`：命中测试逆序找到按钮 → `pressed/hovered` 置位，`press_any = true`，记录 `pressed_input_name`；
   指针抬起且同一目标时发 `UI/Click {handle}`（域内）；悬停目标变化时发 `UI/Hover`；
2. `frame_begin` 末尾派发域内事件：应用层 / 测试订阅者收到 `UI/Click`；网关收到后，若该控件绑定了命令，
   立即广播 `Input/Command`（receiver 为空）；未绑定命令则不外发；
3. `ui_event.frame_publish`：因按下沿发 `Input/MouseFocus`（目标 = 控件输入名 / UI 根 / 外部名）；
4. 焦点系统在下一帧应用焦点并广播 `Input/FocusChanged`；
5. `ui_event.frame_apply`：`system_focus_apply` 把 main/child/modal/text 映射到控件的 `system_focused`；
6. 应用层或 `on_click` 回调处理点击结果（`clicked_consume` 取走单击标记）。

### 6.2 系统语义命令

1. 焦点系统发 `Input/Command`（config.command）；
2. 桥 `event_process` 入队 `commands`；
3. `frame_apply` 逐条 `ui.command_dispatch`：命中绑定控件即激活并出队（激活产生的 `UI/Click` 带 `origin="gateway"`，
   网关不回译），否则保留；
4. `frame_apply` 末尾派发域内事件；应用层 `ui_command_pop` 取走剩余命令。

### 6.3 文本输入（系统会话）

1. `text_route_prepare`：`text_mode && 焦点文本框有输入名` → `ui.text_route_set(true)`；
2. `frame_publish`：提交或预编辑变化时发 `Input/TextSession`（text / preedit / commit）；
3. 系统回传 `Input/Text` → 入队 → `frame_apply` 调 `ui.system_text_apply` 写入焦点文本框；未消费留给应用层。

## 七、与事件系统的关系

**域内（`Ui_Local_Bus`，不经过中转器）**

| 事件 | 触发 | 载荷 |
| --- | --- | --- |
| `UI/Click` | 鼠标抬起同目标 / 键盘激活 / 命令激活 | `handle`（命令激活另带 `origin="gateway"`） |
| `UI/Toggle` | 复选框切换 | `handle`、`checked` |
| `UI/Value` | 滑动条取值变化 | `handle`、`value` |
| `UI/Hover` | 悬停目标变化（连续同目标不重复） | `handle`、`inside` |
| `UI/Activate` / `UI/TextInput` / `UI/FocusChanged` / `UI/TextMode` | 网关入站翻译（预留） | 对应系统事件字段 |

**对外（`Event_Broker`）**

| 方向 | 事件 | 目标 |
| --- | --- | --- |
| 出站 | `Input/Raw` | Focus_System |
| 出站 | `Input/MouseFocus` | Focus_System |
| 出站 | `Input/ChildFocus` | Focus_System |
| 出站 | `Input/ModalPush` / `Input/ModalPop` | Focus_System |
| 出站 | `Input/TextSession` | Focus_System |
| 出站 | `Input/Command` | 广播（网关翻译「命令绑定控件」的域内事件） |
| 入站 | `Input/FocusChanged` | 缓存并映射控件焦点 |
| 入站 | `Input/TextMode` | 文本路由开关 |
| 入站 | `Input/Command` | 命令分发 / 外溢 |
| 入站 | `Input/Text` | 焦点文本框 / 外溢 |

订阅登记在 `attach` 中通过 `Subscribed_Events/Add` 事件完成；退出时发 `Subscriber/Detach`。
外部网络按 `(category, tag)` 由中转器路由；UI 域内为**终端级联**（中心终端 + 端口绑定），不经过中转器。
