# 输入与焦点 · 模块架构

> 模块路径（相对源码根）：`Engine/EngineSystem/src/input/`
> 本模块由三部分组成：输入映射对象与管理器（`mapping/`）、纯解析与轴变换工具（`mapping/Input_Mapping/`）、焦点管理系统（`focus/`）。
> 全链路通过事件系统做定向投递，不新增跨层直连接口。

## 二、模块功能介绍

### 2.1 模块定位

- `Input_Manager`：持有映射对象池、对象名索引、宿主/子对象关系、跨帧按住状态；接收原始输入帧，按映射表产出 `Command` 与 `AxisState`。
- `Input_Mapping`：无状态解析器（键位、修饰、绑定、监听表、轴绑定）与轴值变换。
- `Focus_System`：维护主对象焦点栈、子对象接管、模态闸门与文本模式；是输入链路的焦点权威。

### 2.2 文件清单

| 文件 | 产出 |
| --- | --- |
| `common/输入类型.h` | `Input_Key`、`Input_Binding`、`Axis_Binding`、光标快照等 |
| `common/输入事件.h` | 事件 category / tag / 字段名常量 |
| `mapping/Input_Object/映射对象.h` | `Input_Object`：对象编号、事件终端、映射表、轴表、监听表、能力位 |
| `mapping/Input_Mapping/输入映射.h` | `input_mapping::*` 解析与 `axis_transform` |
| `mapping/Input_Manager/输入管理器.h` | `Input_Manager`：对象池、生命周期、原始输入分发、命令中转 |
| `focus/Focus_Manager/焦点系统.h` | `Focus_System`：焦点栈、模态、文本模式、焦点广播 |

## 三、模块公开接口介绍

### 3.1 `Input_Object`

- 定位键 `uint64_t id`（由 `Input_Manager` 自持的 `Number_Pool<uint64_t>` 分配，起点 1）；
- `Event_Terminal event_terminal`：接收入口绑定到 `Input_Manager::object_dispatch(id, evt)`，发送入口绑定到 `command_relay`；
- 数据：对象名、宿主名、`focusable` / `enabled` / `text_sink`、自身映射表、轴绑定表、轴状态、注入声明/生效表、监听表、轴告警集合；
- 禁止拷贝、允许移动（对象池原地重建需要）。

### 3.2 `Input_Manager`

| 接口组 | 行为 |
| --- | --- |
| `attach()` | 接入事件中转站并登记订阅清单 |
| `object_exist` / `object_is_main` / `object_is_child_of` | 对象关系查询 |
| `object_injected_count` / `object_listening_count` | 注入生效数量 / 监听数量 |
| `object_focusable_get` / `object_enabled_get` / `object_text_sink_get` | 能力位查询 |
| `object_axis_value_get` | 轴状态查询 |
| `key_held_get` / `modifier_mask_get` / `cursor_get` | 按住状态、修饰掩码、最近一帧光标 |

私有主链路：`object_create` / `object_destroy`（级联）/ `object_reload` / `object_update`；`raw_forward` / `text_forward`；`object_dispatch` → `object_map` → `object_keys_process` / `object_axes_process`；`command_relay`。

### 3.3 `input_mapping`

| 接口 | 行为 |
| --- | --- |
| `key_parse` | 键位说明（位域数字或名称）→ `Input_Key` |
| `modifier_mask_of` | 物理键位 → 规范化修饰掩码（非修饰键返回 0） |
| `modifier_parse` | 组合修饰项解析（多项按位或） |
| `binding_parse` / `mapping_parse` | 单条绑定 / 映射表解析（任一项非法则整体失败） |
| `listening_parse` | 监听表解析（只保留宿主自身映射表存在的键位） |
| `axis_parse` | 轴绑定表解析 |
| `axis_transform` | 死区、缩放、反相、钳制；速率型乘时间步长得到位移增量 |

### 3.4 `Focus_System`

| 接口 | 行为 |
| --- | --- |
| `attach()` | 接入事件中转站并订阅输入/焦点相关事件 |
| `frame_begin()` | 帧首统一应用待生效焦点转移 |
| `current_main_get` / `current_child_get` / `stack_size` | 当前焦点查询 |
| `text_mode_get` / `modal_size` | 文本模式 / 模态栈深度 |

事件词汇（category `Input`）：`Raw`、`Command`、`MouseFocus`、`ChildFocus`、`ObjectLinked`、`ObjectDestroyed`、`Forward`、`FocusChanged`，以及模态压/弹与文本会话事件。

## 四、模块内部架构介绍

### 4.1 `Input_Manager` 内部状态

- `Number_Pool<uint64_t> id_pool`：对象编号分配（起点 1，0 保留）；
- `Object_Pool<Input_Object> objects`：定位键为对象编号，投影器返回 `object.id`；
- `name_index`：对象名 → 编号；`children`：宿主名 → 子对象名集合；
- `held_keys` / `last_frame` / `frame_seen` / `cursor`：跨帧输入状态；
- `Binding_Match`：命中绑定、来源对象名、是否来自宿主。

### 4.2 `Focus_System` 内部状态

- `main_stack` / `current_main` / `current_child`：主对象焦点栈与当前焦点；
- `pending_main` / `pending_child` / `pending_child_clear` / `pending_pop` / `pending_valid`：单值待生效槽，同帧后写覆盖前写；
- `modal_stack`：模态条目（对象名 + 压栈者）；
- `text_mode`；`host_of` / `children_of` / `focusable_of` / `enabled_of` / `text_sink_of`：对象关系与能力位镜像。

### 4.3 职责分界

- 输入映射只产出 `Command` / `AxisState`，不修改焦点；
- 焦点系统只对 `Escape` / `Enter` 两条语义做焦点转移特判；
- UI 命中通过 `MouseFocus` 上报，子对象焦点通过 `ChildFocus` 上报；
- 焦点系统变更后广播 `FocusChanged`，输入系统据此决定输入投递目标。

## 五、模块设计/实现细节

1. **编号归 Input_Manager 自持**：对象池不再分配 ID；创建时先 `id_pool.get()`，再 `objects.build(id, Input_Object{})`；卸载时先 `objects.unload(id)`，再 `id_pool.recycle(id)`。
2. **转移延后一帧**：所有焦点转移写入待生效槽，`frame_begin()` 统一应用，避免帧内多次转移互相覆盖。
3. **焦点权威**：输入映射系统不能独立修改焦点；焦点变化只能经 `Focus_System`。
4. **键盘总闸**：焦点不在 UI 主对象时，Tab、回车、空格、文本编辑等键盘输入被拦截丢弃；鼠标输入不受影响。
5. **能力位**：`focusable=false` 拒绝焦点转移；`enabled=false` 保留焦点但丢弃业务输入；`text_sink` 参与文本模式判定。
6. **事件终端**：每个 `Input_Object` 持有独立终端；接收与发送入口都绑定回管理器，避免捕获会移动的对象地址。

## 六、模块运行链路详例

### 6.1 原始输入 → 语义命令

1. 渲染层投递 `Raw`（frame / keys / pointer / axes）；
2. `Focus_System` 处理原始帧，确定当前投递目标（主对象或接管子对象），发出 `Forward`；
3. `Input_Manager` 收到 `Forward` → `object_dispatch(id)` → `object_map`；
4. `object_keys_process` 按键位与修饰掩码匹配绑定，产出 `Command`；`object_axes_process` 产出 `AxisState`；
5. `command_relay` 广播命令；`Enter` 目标为自家子对象时改为子对象焦点请求。

### 6.2 焦点转移

1. `Command` 中的 `Enter` / `Escape` → `Focus_System` 计算目标或弹栈；
2. 写入待生效槽；
3. 下一帧 `frame_begin()` 应用，广播 `FocusChanged`；
4. `Input_Manager` 按新焦点决定后续 `Forward` 目标。

### 6.3 对象创建 / 卸载

- 创建：解析配置 → 分配编号 → `objects.build(id, Input_Object{})` → 写入对象字段与映射表 → 绑定终端入口 → 登记 `name_index` / `children` → 广播对象状态；
- 卸载：级联先卸载子对象 → 移除关系与索引 → `objects.unload(id)` → `id_pool.recycle(id)` → 通知焦点系统。
